## 新会话开工三件事

1. 读本 README + `00-愿景与第一性原理.md`（还没内容就先问老板）。
2. 读 `docs/plans/` 里最新的台账，搞清楚上一步做到哪了，**杜绝重复做已完成项**。
3. 确认自己的角色边界（后面多 Agent 分工后写在这里），只动自己领域的文件。
