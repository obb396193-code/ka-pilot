# V1.3升级指引

为满足客户便捷、高效投放广告的诉求，Marketing API已支持腾讯广告账户无需绑定微信公众号即可投放朋友圈广告，同时全面升级了oCPC/oCPM/定向策略等多项投放能力。
为了保证您的版本升级体验，您可继续使用V1.1或V1.2版本号进行请求，平台会自动适配成V1.3版本请求进行处理，V1.3版本与V1.1、V1.2版本的接口请求地址、请求参数、返回值等暂无不兼容差异。 此升级指引内容仅供参考，请您对照V1.3的具体接口详情进行对接。



## 本次支持的需求内容

1.V1.3允许未绑定微信公众号的腾讯广告平台广告主投放及管理朋友圈广告，同时广告主可在[腾讯广告投放管理平台](http://ad.qq.com/)及Marketing API之间进行跨端的查看及管理操作。

2.本期开放的资源及能力包括：

- 推广目标类型：支持创建/编辑Android应用、iOS应用、电商推广、小游戏推广、微信品牌页、销售线索等。
- 广告类型：现已支持普通广告及SDPA广告的投放流程。
- 流量资源：现已支持朋友圈、公众号文章底部和文章视频贴片大部分创意形式的投放，其中朋友圈创意形式包括：朋友圈基础卡片横版大图16:9（创意形式id：450）、朋友圈“常规大图”的单图800*800尺寸（创意形式id：311）、朋友圈“常规大图”的六图800*800尺寸（创意形式id：643）等。更多创意形式可通过[创意形式查询工具](https://developers.e.qq.com/docs/tools/adcreative_template)或[创意形式查询接口](https://developers.e.qq.com/docs/api/tools/adcreative_template/adcreative_templates_get)了解更多。
- 落地页类型：现已支持微信原生推广页、小程序、自定义链接等。其中，朋友圈已支持双落地页能力，外层落地页可使用微信原生推广页PAGE_TYPE_CANVAS_WECHAT、
  微信简易原生PAGE_TYPE_MOMENTS_SIMPLE_NATIVE_WECHAT、素材放大PAGE_TYPE_FULL_SCREEN_WECHAT等三种。行动按钮选择开启后，则可根据不同推广目标，有不同的按钮文案及跳转链接选择。

***特别说明：**
—投放能力：1）暂不支持同一推广计划下同时投放朋友圈及非朋友圈广告；2）暂不支持朋友圈多创意广告的投放。
—定向能力：1）暂不支持使用公有定向包进行投放。



## 具体对接步骤

### 1.投前准备：

您需在投放端先完成朋友圈头像及昵称跳转页面的创建，并通过[profiles/get](https://developers.e.qq.com/docs/api/business_assets/profiles/profiles_get)获取到该页面的id（profile_id）。或者直接通过API完成朋友圈头像及昵称跳转页面的创建，涉及接口为[profiles/add](https://developers.e.qq.com/docs/api/business_assets/profiles/profiles_add)。

### 2.朋友圈广告投放

1）创建推广计划（campaigns/add）：请选择所需投放的推广目标类型，设置投放速度模式、状态等。
**请关注：**此处campaign_type必须选择
CAMPAIGN_TYPE_NORMAL，原CAMPAIGN_TYPE_WECHAT_MOMENTS枚举值即将废弃。
2）创建广告组（adgroups/add）：请选择投放起止时间、定向等，并设置出价、日预算等。
**请关注：**
①此处的广告版位信息需要使用SITE_SET_MOMENTS（朋友圈）， SITE_SET_WECHAT仅覆盖公众号/小程序流量。
②接口字段中，关于campaign_type = CAMPAIGN_TYPE_WECHAT_MOMENTS的特殊逻辑，均可通过site_set = SITE_SET_MOMENTS进行处理。
3）创建广告创意（adcreatives/add）：请设置创意内容以及相关的播放能力等。
**请关注：**此处必须设置profile_id。
4）创建广告（ads/add）：请在此步骤，将广告组及广告创意关联起来。
**请关注：**目前朋友圈广告单个推广计划下允许设置多个广告组，但每个广告组仅允许关联单个广告创意。
平台各项功能仍在持续演进中，后续具体功能升级点请以[更新日志](https://developers.e.qq.com/docs/start/changelog/api)为准。
