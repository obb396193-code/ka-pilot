        >

        > 1. is_deleted 参数不传时默认为 false，只返回未删除记录。

        > 3. 当根据广告创意 id 进行查询且 is_deleted 参数不传或为 false 时，获取的广告创意列表包含已删除的广告创意。

        > 4. created_time 和 last_modified_time 的 values 值为时间戳，单位为秒，时区为 GMT+8。
