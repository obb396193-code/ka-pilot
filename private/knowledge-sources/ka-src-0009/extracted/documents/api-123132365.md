        wechat_openid，此项填写无效。 请注意，当所填 user_action_set_id 的类型为{WECHAT,

        位长度的字符串。上报 caid 时 caid_version 为必填项，建议上报最新的 caid 版本。 字段长度最小 1 字节，长度最大 64
