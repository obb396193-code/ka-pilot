:::
**提测流程简述**：**提测流程核心是研发完成功能开发/自测/联调（如有）后，提交测试申请，由测试团队验证功能、性能及兼容性，最终输出测试结果并推动问题修复，具体步骤如下：**

**1\. 研发自测阶段**：研发人员完成代码开发后，先进行单元测试、接口测试，验证功能是否符合需求文档（PRD），并修复自身发现的bug。 

**2\. 联调阶段（按需执行）：**若涉及多模块/系统协作（如电商订单模块与支付系统、物流系统对接），研发团队联合相关系统负责人开展联调，验证跨模块/系统接口调用的正确性、数据传输的准确性，解决联调中出现的交互问题，确保整体流程贯通。

**3\. 提测申请提交：**自测与联调（若有）均通过后，研发在项目管理工具提交提测申请，需附上提测版本、功能清单、自测报告、联调报告（若执行联调）、环境配置说明等关键信息。

**4\. 测试准入审核：**测试负责人核对提测资料完整性、环境稳定性（如数据库、接口依赖是否正常），若不满足（如资料缺失、环境报错），退回申请并告知研发整改。
