###### **结果型项目：**
- 持续性活动，在每个小周期内循环过程管理的经典阶段
- 资源相对固定分配
- 目标稳定，流程相对标准化
- 阶段性验收结果，无需到最后阶段

###### **典型项目：**
- 启动阶段：明确项目目标、范围、利益相关者，批准立项。
- 规划阶段：制定详细计划（时间表、预算、资源分配、风险管理等）。
- 执行阶段：协调团队，按计划推进任务。
- 监控与控制阶段：跟踪进度，调整偏差，确保目标达成。
- 收尾阶段：验收成果，总结经验，归档文档，正式结束项目。
