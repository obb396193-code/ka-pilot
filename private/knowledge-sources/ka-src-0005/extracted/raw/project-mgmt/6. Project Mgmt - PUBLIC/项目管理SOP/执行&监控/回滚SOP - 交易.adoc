### 提交回滚
- 提交回滚的时候，可以适当减少批次
- 但无需过分关注，因为提交回滚后，依然可以通过点击完成当前批次，来提高回滚效率
- 紧急情况可以忽略强制忽略Beta批次，第一批次等待等时间
- 至少要保证1/3的机器在正常运作



### 验证发布
- 验证引起回滚的问题是否已经解决
- 通过Arthas检查是否已回滚到目标基线
