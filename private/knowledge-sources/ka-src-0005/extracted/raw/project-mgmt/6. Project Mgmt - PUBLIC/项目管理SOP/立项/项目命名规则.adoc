**一、年份与季度标识**
- **年份：**采用阿里财年后两位，如2025财年简写为“FY25”，2026年简写为“FY26”。
- **季度：**以阿里财年季度定义：“Q1（4-6月）、Q2（7-9月）、Q3（10-12月）、Q4（1-3月）”表示，明确项目的立项时间。



**二、优先级标识及定义**

**1\. 全域战役，简称 “**【**战役**】**”**
- 定义：跨多业务域的核心战略项目，影响整体业务目标达成，需全公司资源协同攻坚，优先级最高。支持Lazada公司战略目标实现，和JD OKR有直接关联，需要多个业务域协同参与的项目，全域战役项目里的子项目也属于全域战役项目；

**2\. 域内战役，简称 “**【**战役**】**”**
- 定义：支持单个业务域或部门团队战略目标实现，和JD- D OKR有直接关联，需要本业务域业产技资源重点投入的项目，域内战役项目里的子项目也属于域内战役项目；

**3\. 域内重点项目，简称 “**【**重点**】**”**
- 定义：支持单个业务域或部门团队战略目标实现，重要性和规模稍弱于域内战役、但也需要业产技重点关注的项目；

**4\. 日常项目 - 跟随敏捷迭代BAU Aone空间命名规则**
- 定义： 一般不需要单独立项，走迭代管理，利用已有的BAU项目空间。如有特殊事情需要单独立项管理（如阶段性的大促事项），请联系各域PMO。
