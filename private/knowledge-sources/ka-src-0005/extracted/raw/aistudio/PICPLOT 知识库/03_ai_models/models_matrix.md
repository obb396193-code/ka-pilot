# 🤖 AI 模型分工矩阵

PICPLOT 项目集成了多家 AI 服务商的多模态模型能力，按业务场景分工如下：

## 1. 大语言模型 (LLM)
负责文本理解、脚本创作、逻辑提取与内容评测。

| 模型名称 | 来源平台 | 主要用途 |
| :--- | :--- | :--- |
| **Qwen3-Max** | 阿里云 (Bailian) | 核心业务逻辑处理、文案切割、分镜脚本生成。 |
| **GPT-51** | Idealab | 角色语音特征提取、复杂指令理解。 |
| **Gemini-2.5-Pro** | Idealab | 海量 Context 场景下的信息提取（如全书实体分析）。 |
| **Qwen-VL** | 阿里云 | 分镜图片自动评测 (Judge)，从 4 张候选图中选出最佳图片。 |

## 2. 图像生成模型 (T2I)
负责将提示词转化为高质量的分镜画面。

| 模型/平台 | 调用标识 | 特点 |
| :--- | :--- | :--- |
| **通义万相 (Plus)** | bailian | 风格稳定，适合多种艺术风格。 |
| **Seedream** | backend | 内部定制模型，具有较高的构图美感。 |
| **Idealab Image** | idealab | 备选模型库。 |

## 3. 视频生成模型 (T2V / I2V)
负责将分镜图转化为动态视频片段。

| 模型名称 | 来源平台 | 备注 |
| :--- | :--- | :--- |
| **Wan2.6** | Bailian | 支持 I2V (单图生视频) 和 R2V (多参考图生视频)。 |
| **Vidu** | Vidu.ai | 生成动态感强，支持固定时长输出。 |

## 4. 语音合成 (TTS)
负责赋予角色声音。

*   **讯飞 (Xunfei)**: 中文表现稳定。
*   **呱呱有声**: 情感表达丰富。
*   **MiniMax**: 现代感强的音色库。
