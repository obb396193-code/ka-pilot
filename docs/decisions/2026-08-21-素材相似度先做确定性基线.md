# ADR：素材相似度先做确定性结构化基线

> 日期：2026-08-21
> 状态：采用

## 决定

一期素材相似查找先基于 B15 已验证的结构化拆片字段做确定性、可解释评分；复刻谱系作为独立事实关系建模。暂不接 Embedding、向量库或模型重排。

## 原因

- PRD 已明确相似素材按钩子、卖点、节奏匹配；
- 当前可以不依赖外部权限和公开契约完成稳定领域基线；
- 可解释分项更适合优化师判断“哪里像”，也能成为未来语义模型的回归基准；
- 复刻关系来自明确业务动作，不能由相似度算法自动冒充。

## 未选方案

- 纯 Embedding：语义能力更强，但模型、数据外发、费用、向量存储和重算尚未冻结；
- 混合检索：作为后续方向保留，先用确定性画像做候选召回和 fallback。

## 后果

- 当前对同义改写的召回可能偏弱；
- 每次结果都有稳定版本、分项和证据不足状态；
- 后续接 Embedding 时不得改写已有确定性分数，需新增独立 scorer/version 并保留历史结果。
