## 二、结论

偏的不止账户池，共 **4 偏 + 4 降级 + 3 缺**：

| # | 项 | 类型 | 根因 |
|---|---|---|---|
| 1 | 账户池做成指标表 | 偏 | PRD 无专节，P09 库存语义没回写 |
| 2 | 投放任务缺"准备→投放"阶段/就绪度/SOP 进度 | 偏 | PRD 只写了六页签和 pacing，REQ-028 的"全过程串联"没落对象 |
| 3 | 管理看板没有页 | 偏 | 拆散成日报负责人版 P1 + rollup 未开发 + 归因树 P2 |
| 4 | 工作流节点模型没进契约 | 缺 | B7 内核有，契约只写 graph JSONB；前端画布无从对起 |
| 5 | 策略中心无契约对象 | 缺 | PRD 定义摇摆（分析视图 vs 方案库），老板 9-5 暂缓 |
| 6 | 公共资产治理契约 ❌ | 缺 | B20 内核有，未冻 |
| 7 | Agent 帮做表（REQ-036）、Agent 帮编工作流（REQ-064） | 降级 | 明确要求，现 P2 |
| 8 | 开户测试跟踪 4.7、优质户复制 4.8 | 降级 | 老板 8-24 每日闭环里的动作，现无优先级 |
| 9 | 官方模板缺"开户到基建" | 降级 | 原型 P11/P12 有，PRD 模板清单漏 |
| 10 | 工作台缺"运行中的工作流"面板；Agent 缺 Patch 建议 | 小缺 | 原型有，契约无 |
| 11 | 账户池缺批量→变更集组入口 | 小缺 | 变更集单账户三键 |

**没偏的**：原子能力工具箱、自动化规则与解释、钉钉卡片、知识库复刻 CR、素材 demo 化（老板 8-24 拍的）、基建管理、数据源绑空间、九项导航、数据分析主体。

## 三、处置提案（老板拍板后执行）

**A. 立即冻 v1.5.1（半天，进 migration 015 / R-014）**
1. 账户池：`pool_status` 九态 + 产品归属 + list 扩 + `GET /accounts/pipeline` + `POST /changesets/batch` + 官方模板「新任务开户到基建」（已拍）。
2. 投放任务：`tasks.stage ∈ preparing|opening|recharging|building|cold_start|delivering|ended`；`GET /tasks/:id` overview 加 `readiness:{accounts,recharge,products,materials,strategy,infra}`（各 0-100% + 缺项列表）、`sop_progress`（阶段节点+完成时间，来自绑定的工作流 run）、`blockers[]`（来自 open 工作项/派发）；列表加 stage 与就绪度六段；页签加「SOP 与自动化」。
3. 工作流节点模型：冻 `graph.nodes[].type ∈ trigger|query|compute|condition|agent_analysis|changeset|human_confirm|execute|wait_reconcile|notify` + 节点属性 `{executor_identity, side_effect: read|write|external, idempotency: key_required|none, retry:{max,backoff}, timeout_ms, permission_scope}` + 校验/模拟运行/发布端点 DTO；工作台加「运行中的工作流」面板 DTO。
4. 管理看板：不新增导航，做成**工作台负责人视图**（role=lead|admin 默认）：目标达成/累计消耗/现金 CPA/健康任务数/预算缺口六卡 + 风险与机会（按任务聚合工作项）+ 团队阻塞（派发/升级聚合）+ 需要拍板（approvals）；差距树/AI 提效仍 P2。
5. 小缺：Agent Patch 建议 DTO（`{before,after,accept:all|partial}` 作用于 saved_views/report_config）；公共资产治理最小契约（assets 五态 + 元数据，UI 两态）。

**B. 优先级重排（不改契约，改缺口地图与派活顺序）**
- 4.7 开户测试跟踪、4.8 优质户复制 → **P1**，排 R-014 后（老板每日闭环）。
- 3.9 Agent 帮做表、5.3 Agent 帮编 → **P1**，排 R-010b Agent 之后（REQ 明确要求）。
- 策略中心：维持老板 9-5 裁决（先不设计），但缺口地图标为"明确要求·待定义"，不再写 P2。

**C. 前端顺序**（老板已拍）：登录 → 数据分析 → 账户池 → 工作台 → 投放任务；账户池、工作台、任务三页等 v1.5.1 冻完再做。
