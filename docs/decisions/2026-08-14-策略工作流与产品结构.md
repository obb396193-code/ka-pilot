# 决策：投放策略、工作流与产品结构边界

> 日期：2026-08-14  
> 状态：老板已确认方向，详细字段和实现仍待后续评审。

## 已选方案

### 1. 投放策略是业务打法

投放策略描述任务使用什么版位、投放方式、RTA、出价、预算、账户结构、商品素材组合和阶段打法。策略中心是打法库、分析与验证中心，不承担流程编排。

### 2. 开户到监控属于工作流

开户、充值、基建、启动投放、跑量监控、异常推送和效果回收由一条可恢复工作流串联。策略提供业务参数，工作流负责连续执行。

### 3. 自动化规则只负责触发

自动化规则定义何时、对谁、在什么数据和安全边界下触发已发布工作流。“为什么没触发”放在自动化和运行中心，不放在投放策略页。

### 4. 官方内置与用户自建共存

每个模块都提供官方内置资产，同时允许用户保存个人资产、复制修改、团队共享和高级自由创建。普通用户默认不面对空白画布。

### 5. 钉钉卡片按风险分级

- 只读动作可直接运行；
- 低风险动作卡片确认后运行；
- 媒体写操作在卡片展示变更集后确认；
- 大批量或高影响动作跳 Web 查看完整明细后确认。

本阶段暂不设计钉钉群数据范围治理。

## 未选方案及原因

### 未选：策略中心再做一套画布

会与工作流画布、任务 SOP 产生重复的节点、状态和日志，用户也难以区分。

### 未选：把开户到监控定义成投放策略

该链路描述的是动作顺序和运行状态，不是广告业务打法。

### 未选：所有用户首次进入空白设计器

普通优化师的价值来自直接完成日常工作，空白报表和工作流画布会显著增加学习成本。

### 未选：所有写操作都在卡片内直接执行

高影响操作需要完整目标明细、风险说明和更宽的确认界面，卡片只适合摘要。

## 影响

- 产品只有一个工作流画布，位于自动化中心。
- 投放任务详情展示 SOP 运行阶段，不另建画布。
- 策略资产的验证指标侧重业务效果；工作流资产侧重运行稳定性。
- 页面原型和产品文档按新的对象边界重做 v2。
