# 决策：结算单使用受限公式与冻结快照

> 日期：2026-08-21
> 状态：B19 实施基线

## 选择

每期结算模板显式声明字段、来源、受限表达式和对账容差；月中试算可反复生成预览，人工修正形成前值校验的事件链；正式出单冻结整个值快照和所有上游 fingerprint。

## 没选

- 不执行 Excel/JavaScript/SQL 公式字符串：安全边界和可回放性不足。
- 不硬编码固定结算列或 `/1.09`：老板已明确不同期次字段会变、返点系数按渠道和生效日版本化。
- 不让 Agent 计算或改数：确定性结果必须可逐字段复算，Agent 未来只解释差异。
- 不覆盖旧单：模板升级、事实补齐或人工勘误都应形成新版本/新运行。

## 代价

一期模板表达力只覆盖基础四则运算和字段比较；复杂业务公式需要新增版本化运算符并经审查，不能靠任意代码绕过。
