# 账户 ID 统一键纠错

> 日期：2026-08-24
> 状态：老板已批准，知识资产层立即采用
> 范围：只纠正 `ka-src-0010` 的账户 ID 假设；不修改冻结 PRD/Contract，不顺推其他对象。

## 决定

- KA 与平台的账户 `account_id` 相同。
- 账户 canonical 联合键为 `(workspace_id, media, account_id)`。
- 不建立账户 ID 双命名空间映射表。
- `task/product/material/adgroup` 等其他对象 ID 是否一致仍为 `unresolved`（待核证），必须逐对象取证，不能从账户结论顺推。

## 被否决的旧方案

旧评估根据原始资料中的说法，提出“两套账户 ID namespace”和账户 ID 映射表。该假设已被老板提供的实证否定；继续保留会制造无必要的数据层、错误 JOIN 风险和双写漂移。

## 修改边界

本决定只修正知识资产评估、检索说明、审查信箱和回归校验。原始资料保留原样用于来源溯源；catalog 的 `review_pending`、`pending`、`not_ready` 状态不变。冻结 PRD/Contract 如需同步，由对应 owner 另行处理。
