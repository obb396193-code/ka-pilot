# 决策：Claude 审核不阻塞内网交付

> 日期：2026-08-24  
> 状态：老板已拍板

## 决策

Claude/arch 恢复时间不确定，因此 Claude 审核从“部署前置门”改为“上线后的独立复审门”。Codex 当前交付目标不是候选设计或 mock，而是：

1. 功能实现完整；
2. 本地自动测试、构建和 E2E 通过；
3. 与真实内网数据/OS/Multica 通路联调；
4. 部署到内网 daily/FaaS；
5. 使用真实但受控的业务场景验收，达到可用；
6. Claude 恢复后审查现有实现，提出修改并继续迭代。

## 两条独立状态轴

交付状态：

```text
draft → implemented → integrated → deployed_internal → runtime_verified
```

审查状态：

```text
codex_prechecked → claude_review_pending → claude_approved | changes_required
```

`claude_review_pending` 不阻塞 `deployed_internal/runtime_verified`。但安全、数据正确性、写操作确认门、凭证泄露和不可恢复数据风险仍是内网部署前硬门。

## 没选的方案

- **停在候选版等 Claude**：未选，恢复时间未知，会让可实现、可联调的工作长期停滞。
- **跳过审查直接生产化**：未选。Codex 预审、本地门禁和内网受控验收仍必须完成；Claude 后续复审仍保留。
