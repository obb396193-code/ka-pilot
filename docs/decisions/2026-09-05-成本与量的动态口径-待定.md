# 成本与量的动态口径（2026-09-05 老板口径，公式待定）

> 状态：**待定**。本文记录老板 9-5 的口径原话和 arch 的候选公式，供后面设计时用；不改 `metrics.md` 已冻结公式。定稿后进 metrics.md + schema.sql。

## 老板原话（要点）

- 团队内部考核：给一条**成本线**（考核价），在这条线内**尽可能跑量**。
- 有的任务有**日预算卡**（一天只能跑 10 万 / 100 万），在预算限制下把成本做得更好。
- **量和成本都要看**。有时为了跑量稍微超一点成本；有时为了拉低前面的累计成本又要控量。
- **按月结算**，所以要看全月或多少天的累计成本，不是只看当天。
- 这是动态的，**判断交给优化师**，产品把它展示出来就行。

## 现状对照（契约里已有 / 缺）

| 项 | 现状 | 缺什么 |
|---|---|---|
| 达标 `on_target = real_cpa <= assessment_price` | 有，无时间窗（隐含按日） | 窗口参数：日 / 月累计 / 任务期 |
| 成本空间 `cost_space = assessment_price × real_conversion − cash_cost` | 有，无时间窗 | 同上；且用 `cash_cost` 而 `real_cpa` 用 `cost`，口径要统一说清 |
| 任务 pacing（v1.3） | 有：达成率、剩余天数、7 日均速 | 只算量，不算"剩余天数内可承受的成本" |
| 任务 `budget`（总预算） | 有 | **日预算卡**没有列，也没版本化 |
| 六 KPI 卡 | 消耗/真实CPA/达标率/成本空间/BI量级/待处理 | 达标率、成本空间没标窗口；没有"日预算使用率" |

## 候选定义（待老板确认后冻结）

设窗口 W ∈ {当日, 月累计 MTD, 任务期}，默认 **MTD**（结算口径）：

```
MTD 真实CPA        = Σ_W cost / Σ_W real_conversion
MTD 达标           = MTD 真实CPA <= assessment_price(生效版本)
MTD 成本空间       = assessment_price × Σ_W real_conversion − Σ_W cash_cost      （>0 = 到目前为止还没超线的钱）
月末外推 CPA       = (Σ_W cost + 当前日速率 × 剩余天数) / (Σ_W conv + 当前日转化速率 × 剩余天数)
剩余天可承受日CPA  = (assessment_price × 预计月转化 − Σ_W cost) / 预计剩余转化    （要月末达标，后面每天最多花到多少）
可放量空间(元)     = MTD 成本空间 / 当前真实CPA × assessment_price 近似，或直接给"在成本线内还能多花 X 元"
日预算使用率       = 当日消耗 / daily_budget_cap
```

呈现原则：**只算不判**。工作台/任务页并排给「量：达成进度 · 日预算使用率」和「成本：MTD 达标 · 成本空间 · 月末外推」，红黄绿阈值由优化师在个人视图里自己设，产品不默认判"该关"。

## 要老板定的 4 个问题（做的时候再问）

1. 考核窗口是**自然月**还是**任务期**？跨月任务按月切还是整期？
2. 月累计用**现金消耗**（扣返点折算）还是**账面消耗**？现在两个公式不一致。
3. 日预算卡是**任务级**还是**账户级**？会中途改吗（要不要像考核价一样版本化）？
4. "稍微超一点成本"有没有容忍带（例如 +5% 显黄不显红）？
