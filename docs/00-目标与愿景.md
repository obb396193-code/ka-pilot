# 投放 Agent · 目标与愿景

> 建立：2026-08-13
> 状态：**首轮口述整理中**。已明确的内容按“现状 / 目标 / 待补”记录；未明确处不代笔猜测。
> 规则：本文件只写"我们要做什么、为什么"，不写实现方案。方案进 `docs/plans/`。

## 0. 业务背景与发起动因

### 已知现状（老板口述）

- 组织位置：淘宝集团用户增长 KA 部门，老板本人是**快手渠道优化师**。
- KA 部门负责淘宝 App 各类任务在抖音、腾讯、快手、百度等外部渠道的投放获客。
- AI 浪潮下，部门要求各业务线走向 **AI Native**；技术部门和业务部门都在做产品与业务改变。
- 技术侧已有产品产出，但其具体能力、使用情况和边界，老板后续补充。
- 业务侧比技术侧更贴近真实投放工作流和业务判断，但会受到数据、接口、系统等权限约束。
- 业务内部还存在渠道边界：如果产品要走向全渠道，需要证明产品价值，并争取其他渠道的采用与协作，不能只完成快手单点功能。

### 目标方向（尚未收敛成产品定义）

- 做出一款**真正帮助 KA 部门广告提效**的产品，而非只满足 AI Native 形式或展示需要。
- 服务范围不预设为“快手优化师个人工具”；目标用户可能包括优化师、运营、KA 负责人及更高层级。
- 产品建设与组织动作同步设计：除了功能和技术，还要考虑权限获得、技术与业务的协作/博弈、跨渠道扩张、使用推广与向上汇报。
- 前端体验与视觉呈现要明显优于现有内部产品；它是当前明确的差异化抓手之一，但最终价值仍要由业务提效证明。

### 待补

- 技术部门现有产品做到了什么程度、真实使用率和主要缺口。
- 业务侧当前合法可获得的数据、接口和平台权限。
- KA 各角色的具体工作流、痛点和决策需求。
- AI Native 的考核机制、汇报节点和资源窗口。

## 1. 第一性原理：这件事的本质是什么

先不谈产品形态，先把问题拆到不能再拆。

### 1.1 投放优化师这份工作，本质在做什么

【待老板继续口述】

待回答的问题（我会按你的口述整理，不自己填）：
- 一天里真正花时间的动作是什么，各占多少时间？
- 哪些动作是**判断**（需要经验和上下文），哪些是**搬运**（取数、对表、填表、截图、发群）？
- 一个决策做对做错，代价差多少？（这决定 agent 能不能自动做）

### 1.2 现在的痛在哪

当前只明确了**产品与组织层**的矛盾：技术侧有权限和基建，但未必足够懂业务；业务侧懂场景，也想定义产品，但存在权限和跨部门/跨渠道协作约束。

优化师、运营、负责人在日常工作中的具体业务痛点，仍待老板继续口述，不从历史方案倒推。

- 最耗时间的是什么？
- 最容易出错/漏看的是什么？
- 最烦但绕不开的是什么？

### 1.3 为什么现在能用 agent 解，以前不能

已知机会窗口：部门正在推动 AI Native，业务与技术两侧都在寻找产品化落点。

Agent 能否解决、应该解决到哪一步，仍需结合现有产品、数据权限和真实工作流再判断。

## 2. 我们要做什么（产品定义）

### 2.1 一句话定义

**暂定方向，不是最终定义：** 面向 KA 多角色、以真实广告提效为结果的投放 Agent 产品；从快手一线场景出发验证，同时保留全渠道扩展目标。

待补完现有技术产品和业务工作流后再收敛，当前不提前锁死形态。

### 2.2 服务对象

| 用户层级 | 当前结论 | 需求待补 |
|---|---|---|
| 优化师 | 明确在范围内，不限于老板本人 | 高频动作、判断节点、跨账户管理 |
| 运营 | 明确在目标范围内 | 大盘、任务管理、异常归因等具体需求 |
| KA 负责人 | 明确在目标范围内 | 经营视角、团队效率、汇报与资源决策 |
| 更高层级 | 明确在目标范围内 | 结论粒度、使用频率、决策场景 |
| 其他渠道团队 | 全渠道目标下的潜在使用者，尚未验证 | 各渠道差异、迁移成本和采用条件 |

外部商业化用户当前未被提出，不纳入现阶段定义。

### 2.3 明确不做什么

- 不把产品限定成老板个人或快手渠道的单点自用工具。
- 不为满足 AI Native 汇报而做没有真实业务价值的展示壳。
- 不在权限未明确前假设可以获得媒体或内部系统接口。
- 不把 ContentRadar 的仓库、契约或业务结论混入本项目；只能复用已形成的产品建设经验与能力。

其他边界待老板继续口述。

## 4. 愿景（终局形态）

目标蓝图：成为 KA 部门多渠道、多角色都愿意使用的投放提效产品，并形成业务侧可证明、可推广的 AI Native 成果。

当前仍处于上下文收集和产品定义阶段，尚未验证具体产品形态、渠道扩展路径与组织采用路径。

引导问题：
- 一年后这东西长什么样，谁在用，替代了原来哪些动作？
- 最理想状态下，你早上打开它看到什么、做几个动作就收工？
- 它的边界在哪——哪些判断永远留给人？
