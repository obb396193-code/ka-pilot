## 4. 最小 f.yml 模板

worker 定时：(a) HTTP 函数 + autopilot schedule trigger（cron）定时 POST——OS 实测 autopilot cron 可用；(b) 函数组应用 ScheduerX 定时模板——原生 timer 但链路更重。建议 (a)。

## 7. ka-data 快照一致性（真实执行）
| 问 | 答 |
|---|---|
| 固定不可变版本号 | 无。health 的 version=0.1.0 是代码版本；数据无 build_id |
| 库存/日事实导出方式 | snapshot_daily（按 ds 快照表）+ dwd_* 增量表；每行带 updated_at（构建批次时间戳） |
| 分页两次读之间源会变 | 会变——近几天 ds 每日重建（ds=20260905 在 09-06 建、09-07 又改 314 行）；同一 ds 内有多个 updated_at 批次。历史 ds 稳定，近 3 天 ds 会动 |
| 单条 SQL 一致 | 一致——同查询连跑两次 rowCount=290、sum_cost 相同（SQLite ro 单语句原子） |
结论：单条 SQL（不分页，LIMIT≤10000）原子一致安全；跨分页不保证；无版本号可 pin。可行策略：① 只同步历史稳定 ds；② 按 updated_at 批次过滤取同一构建批；③ 单 ds 单条 SQL 一次拉完（≤10000 行）。
