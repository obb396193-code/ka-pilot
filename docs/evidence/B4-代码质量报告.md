## 复杂度与安全

- 新增生产文件执行 `complexity <=10`、`max-lines-per-function <=100`；初检 `computeTaskPacing` 复杂度 12、`taskFacts` 17，拆出日期、预计量、缺失事实等纯函数后复检 0 warning；
- SQL 值全部参数化；动态 SQL 片段只复用模块内常量 `METRIC_AGGREGATE_SQL`；
- 任务、任务账户关系、考核价和任务指标查询全部显式带 `workspace_id`；考核价写入额外验证 `changed_by` 属于同 workspace；
- 任务账户有效期使用事务级 advisory lock，两个并发重叠写入只允许一个成功；
- 任务指标使用 `EXISTS` 关联，历史坏数据存在重叠关系时也不会重复汇总 canonical 指标；
- 未引入动态命令执行、真实凭证、真实账户 ID 或媒体写操作；测试全部使用脱敏假数据。

## 关键边界测试

- asOf 为完整数据日，剩余日不含 asOf；结束日、已结束、零目标、超额完成、缺数据和调用方业务日历均有覆盖；
- 最近 7 日只截取最后 7 个完整数据日，零量日作为真实事实保留；
- 同一个外部 task_id 在不同 workspace 可隔离读取；
- 任务账户有效期拒绝交叠，并覆盖并发写入；
- 考核价同日多版本按最新 id 生效，保留 changed_by/evidence_url，跨租户 actor 被拒绝；
- canonical 指标只在任务账户关系有效日内汇总，不跨租户、不双计；
- 日报比例从聚合分子分母重算，零分母保留 finite/infinite/undefined 状态；缺少汇总、任务指标、考核价、目标或预算时输出字段级 missingFacts。

## 如实边界

- `task_id` 来源仍由外部适配器提供，尚未核验奇航任务主数据准确性；
- 现有 `task_accounts` 契约的 UNIQUE 缺 workspace 且没有 FK/排斥约束，仓储只能为通过本仓储的写入兜底；
- 没有 B4 Web API Route、真实任务同步 Worker 或 UI DTO；
- 没有硬编码日报“12 模块”、钉钉卡片、知识库归档或角色裁剪；
- 没有考核价变更通知/已读确认/历史指标重算；
- pacing 是日级事实函数；业务日历由调用方显式传入，小时级 pacing 尚未实现。
