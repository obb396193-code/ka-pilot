## 5. 自审发现与修复

1. 初版整段 ASR 输出解析 complexity=16、字幕解析 complexity=11；拆为对象形状、文本、安全字符和时间轴的单职责函数，终态均≤10。
2. 初版 adapter 倚赖上游 Domain 已校验媒体身份；增加自身防御性校验，非法 SHA、handle、时长在 transport 调用前阻断。
3. Domain 初版 whole-text 只检查字段描述符；补 plain-object prototype 门，拒绝自定义类实例和 getter-backed 返回。
4. `whole_video` 初版只限制为全片单段；进一步强制结果角色为 `other`，避免模型把全文证据伪装成精确 Hook 时间段。
5. SDK opt-in 前两次出现一次通用执行失败、一次 sidecar readiness timeout；独立 gateway E2E 通过后第三次 opt-in 6.55 秒通过。未通过修改业务断言掩盖；终态按最终独立复跑记录，同时保留该本机启动抖动事实。
6. Docker Desktop 在一次并行覆盖率运行间退出；重启隔离 PG 后，DB 全量、Worker 全量和 Worker 全仓覆盖率均重新执行并通过。
