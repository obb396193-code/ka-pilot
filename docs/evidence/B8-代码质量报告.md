## 4. 正确性与安全边界

- 只接受严格 `{blocks:[...]}` 外层；拒绝裸数组、未知顶层字段、非 JSON、非有限数、循环、危险 key、accessor、Symbol、数组洞和数组自定义属性。
- blocks 内保留未知 BlockNote 结构，避免后端与编辑器版本升级强耦合；`wikilink` 和 `business_ref` 由独立严格 parser 校验。
- blocks/depth/nodes/string/serialized bytes 五层资源限制；总字节在遍历时累计，不先复制超大文档。
- 文本投影只取 `text` 和 wikilink title，不把内部 ID/props 噪音送进搜索索引。
- 文档指纹以版本前缀 + canonical JSON 做 SHA-256；object key 顺序不影响，数组顺序和内容变化会影响。
- 双链以 UUID itemId 为真相，首出现去重；自链和坏 ID 不建边。目标 resolver 强制 workspace+actor 上下文，只可返回请求集合。
- 跨 workspace、无权和不存在目标统一 `target_unavailable`，结构化诊断只含类型、错误码和 path，不回显非法 payload/目标 ID。
- business ref 只允许 9 类对象和受限 opaque ID；label 是显示缓存，snapshot/cutoff 为证据版本，不作为对象真相。
- Agent 搜索请求必须有 workspace+actor；检索适配器先按身份过滤，领域边界再复核文档和业务对象权限。跨 workspace/非法 citation 整批 fail-closed，无权文档/业务引用在进入 Agent 前移除。
- 无 eval/new Function/子进程/Shell/任意 SQL/URL fetch；无凭证、token 或原始敏感 payload。
