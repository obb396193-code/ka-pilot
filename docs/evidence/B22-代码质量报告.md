## 4. 规范、安全与资源边界

- Domain、DB、Worker、DingTalk 四包 typecheck/lint 通过。
- 四包 `npm audit --audit-level=high` 均为 0 vulnerabilities。
- 新增生产函数 complexity≤10、单函数≤100；新增生产文件均≤300 行。
- endpoint 在配置和 Transport 双层固定为 `idealab.alibaba-inc.com/api/openai/v1/audio/transcriptions`，拒绝任意 HTTPS 主机造成 AK 外泄。
- redirect 禁止；AK 不进入序列化配置、观测、错误、测试输出或文档。
- 输入文件必须是绝对路径的常规非符号链接；FFmpeg 使用 `spawn(shell:false)`，固定音频参数。
- WAV 与响应均有字节预算；Provider 响应 plain object/字段集合/文本/usage/UTF-8 全部 fail-closed。
- 临时 WAV 在成功、Provider 失败和解析失败后都释放；清理失败不覆盖更早主错误。
- 相对 B21，public Contract、DB migration、前端和生产 Runtime 0 diff；真实媒体写操作 0。

## 5. 第一性原理自审与修复

1. **AK 可被配置投递到任意 HTTPS**：初版只校验 HTTPS。新增 host/path/port/query/fragment 双层固定和反例，封死凭证出口。
2. **复杂度掩盖错误路径**：初版构造校验 complexity=22、WAV extract=11、Transport 420 行；拆为 error/response/validation 单职责模块，终态函数≤10、文件≤300。
3. **MP4 直接调用必失败**：按真实 `CE-009` 证据固定 WAV PCM s16le/16kHz/mono，不做格式猜测或盲重试。
4. **Provider 扩字段污染领域契约**：严格解析 `{text,usage}`，Transport 只向 Adapter 返回 `{text}`；usage 只进内部数字观测。
5. **无时间戳被伪装成逐句结果**：继续复用 `whole_video`，不制造 segment、language 或 duration。
6. **重试放错层造成重复计费**：Transport 单次调用；仅暴露错误类别，由未来 Job 按幂等、预算和额度统一决策。
7. **临时文件泄漏或清理错误遮蔽主因**：所有路径 release；主错误优先，成功后清理失败则显式失败。
8. **OS 实证与产品实证混淆**：OS 证据独立归档；opt-in 产品烟测默认跳过，状态页明确未执行。
