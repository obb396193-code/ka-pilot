## 5. 第一性原理自审与修复

1. **字段每月变化**：不写死结算列；template ID/version/fingerprint 固定字段、顺序、映射、公式、汇总和检查。
2. **系数不能被误当金额求和**：aggregation 必须逐字段显式声明，只有 numeric 类型可 sum；任一行缺值时总计 null，不按部分行凑数。
3. **返点与容差不能拍脑袋**：`/1.09`、渠道系数和匹配阈值均不内置；模板提供 absolute/relative/either 容差和 block/warn。
4. **自由公式是执行漏洞**：只支持有深度/节点预算的 AST，字段引用需存在且为 numeric，循环失败。
5. **实时数混入结算**：预览只接受 `offline_settlement`，且 dataCutoffAt 不得早于 periodEnd。
6. **人工改数覆盖证据**：修正必须命中可修字段并带 from-value、to-value、理由、用户、时间；同 ID 冲突失败，多步链稳定回放。
7. **旧模板改变旧单**：冻结输出内嵌 template snapshot、所有值/总计/检查和上游 fingerprint；只保存模板 ID 不够。
8. **重算 hash 伪造 ready**：冻结前继续语义校验模板、时间、修正、行字段/检查形状、检查重算和总计重算，外层 hash 不是唯一防线。
9. **Agent 心算污染金额**：模块无 Agent 入口；未来模型只能解释确定性输出，不能产出结算值。
