## 1. 交付范围

- 素材 CDN 类型门：标准视频直接准入，allowlist VIDEO 的 octet-stream 仅带强制容器校验标记准入。
- 安全下载：逐跳来源重验、声明/实际长度一致性、流式上限、总超时、随机临时目录、SHA-256 与幂等清理。
- 字幕领域：平台字幕优先、云 ASR 端口兜底、严格时间轴和稳定指纹，无本地 ASR。
- FFmpeg 拆片：视频流/时长/尺寸探测、scene/hard-cut、完整 Shot 时间轴、Hook/全片联系表、抽帧上限和失败占位。
- 证据与分析：稳定字幕/镜头 ID、严格 JSON Schema、证据引用、完整分段闭环、无源后台指标拒绝。
- Agent 接线：版本化 Prompt、Claude Agent SDK、localhost 多模型网关、无工具结构化输出和 Provider/model/profile 指纹。
- 可恢复编排：按内容 SHA 保存阶段 checkpoint；版本相同复用，分析配置变化只重跑分析。

## 5. 自审修复

1. 真实 CDN 返回 octet-stream，与 B12 仅允许 `video/*` 冲突；改为仅 allowlist VIDEO 有条件准入，并强制 FFprobe。
2. 素材行没有可信 duration，不能安全并行字幕和视觉；首次先 FFprobe，checkpoint 命中后再跳过重复计算。
3. 初版只记录 Prompt 的动态 SHA，同版本文件可静默漂移；增加固定模板 SHA，漂移即 `template_drift`。
4. 下载正文补齐 content-type/length 漂移、短包、空 body、实际超限、总超时和 partial 清理反例。
5. 补齐媒体进程不存在、超时、输出截断和危险参数测试；B13 每个生产模块的行/分支/函数覆盖均超过 80%。
6. 尝试设计真实帧多模态工具时识别到外发边界未获批准；未绕过安全审查，改为明确阻断视觉 payload，并禁止模型声称看过图像。
