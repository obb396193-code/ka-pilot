## 5. 第一性原理自审与修复

1. **公共版本被个人编辑污染**：定义版本不可变，修订和复制都生成新 draft。
2. **旧验证替新定义背书**：validation 同时绑定 assetVersionId 和 definitionFingerprint。
3. **一次通过永久有效**：晋级 verified 读取截至晋级时最近一次验证；后续 failed 会覆盖旧 passed。
4. **跨资产挪用使用量**：usage fact 同样绑定版本和定义指纹，冲突事件 ID fail-closed。
5. **重算 hash 伪造状态**：除外层 fingerprint 外，重新走状态链、验证时序、废弃事件和元数据规范化。
6. **成功率拍脑袋**：只由 successfulRuns/totalRuns 计算；定性验证返回 null，不伪造 100%。
7. **权限被复制**：治理模型没有 credential 字段，copy 只保留 source ref；授权由服务层重新判断。
8. **废弃资产继续背书**：deprecated 后禁止新增验证，废弃必须写原因，可显式指向非自身替代版本。
