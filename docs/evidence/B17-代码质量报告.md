## 5. 第一性原理自审与修复

1. **未确认归因分母**：初版默认 `realConversion≤click` 并把区间叫 real CVR；这会把点击归因假设写死。现改为策略显式选择 `click|exposure`，输出统一叫 inference rate；选择 click 时才要求转化不大于点击。
2. **少量转化误判**：最低 CPA 不直接成为 leader；必须先过所有样本门和有限 CPA。
3. **效果很小也标领先**：增加版本化最小 CPA 改善率；平局使用稳定 ID 只为排序，结论仍是 `effect_too_small`。
4. **只赢一个对手**：观察分离必须让方向候选的区间下界高于所有其他合格候选上界，不只比较第二名。
5. **重复抓取双计**：同 sourceFactId 完全相同去重，字段冲突直接失败。
6. **输入顺序漂移**：事实先按 ID 排序、产品/素材再稳定排序，乱序和重复位置不改变结果/fingerprint。
7. **资源放大**：补 10,001 事实、1,001 格和聚合计数/金额越界反例，均 fail-closed。
8. **因果误导**：枚举刻意使用 `separated_observation/observedLeader`，没有 winner、significant winner、recommend execute 或自动写操作。
