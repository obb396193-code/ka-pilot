## 5. 第一性原理自审与修复

1. **资源放大**：初版用 `Promise.all` 同时生成全部帧墙页，500 镜会并发约 14 路 FFmpeg；改为固定 2 路并发并增加测试观测。
2. **旧缓存伪完成**：B14 film checkpoint 没有 `contactSheets.shots`，若直接复用页面会看不到帧墙；新增页清单完整性检查，旧 film 只重跑 FFmpeg。
3. **Schema 身份漂移**：输出字段已变化但最初仍写 schema v1；增加 `MATERIAL_TEARDOWN_SCHEMA_VERSION=2`，Prompt 版本或 Schema 不匹配时在调用 Agent 前 fail-closed。
4. **证据错位**：初版只验证 evidence ID 存在，精确时间段可引用不相交的后段字幕；新增时间相交与至少一条文稿证据门禁。
5. **视觉冒充语义**：初版有时间字幕下的语义段可只引用 shot；现在所有语义段都必须包含文稿证据，whole-video 模式更只能引用全文字幕。
6. **页级失败**：逐镜头帧墙失败未升级为整任务失败，保留真实 unavailable 状态；不拿缺图冒充黑屏或空镜。
