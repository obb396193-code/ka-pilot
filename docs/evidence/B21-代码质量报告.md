## 第一性原理自审

1. “没触发”不能只有一条自由文本：输出 version-bound、evidence-bound 的结构化检查快照。
2. 未评估不能伪装通过：无 blocked 但存在 not_evaluated 时明确 incomplete。
3. 多项失败不丢证据：保留全部 blockingChecks，同时用配置顺序选第一阻断。
4. 重试时间不能倒流：retryAt 只允许 blocked 使用且必须晚于 evaluatedAt。
5. 通过门禁不等于已执行：状态命名 eligible，不产生 run/execution 字段。
6. 模型不能发明原因：模块无 Agent；所有 gate 由 Scheduler/权限/数据/冲突等确定性执行器提供。
7. 重算外层 hash 仍不能改 next action：parse 时重新构建派生状态并逐项比对。
