## 1. 交付范围

- 广告 ID 结构化分页枚举：校验 page/pageSize/total、空页、页数和 ID 数预算。
- 权威证据双钥匙：只有 `complete + confirmed_equal + 独立证据指纹` 才可输出 `adIds`；结构伪造也无法绕过运行时门。
- 奇航素材池只读客户端：严格业务 envelope、分页进度、total 稳定、重复冲突、行/页/字节预算和脱敏观测。
- 视频来源准入：默认空 host allowlist 全拒绝；每次跳转重验 host；HEAD 不支持时仅请求 `bytes=0-0`；直接 IP、非视频、未知/零长度和超限均阻断。
- 部署配置仅增加素材 host allowlist、最大字节和可选素材池 HTTPS URL；未接生产 Runtime 或公开 API。

1. 初版调用方只需传 `confirmed_equal` 即可升格；已增加独立映射证据指纹、类型和验证时间，并在 `requireAuthoritativeAdIds` 再次运行时校验，阻断结构伪造。
2. 广告分页和素材分页主函数复杂度超 10；已拆为状态推进、继续条件和结果构造，复杂度门禁通过。
3. 素材 transport 错误可能透出带查询参数 URL；已统一映射为无明细稳定错误。
4. 视频 host allowlist 曾可显式放行其他 IP；已拒绝全部直接 IP，只允许显式域名/子域名模式。
5. 零字节响应曾可进入 ready；已按未知/无效长度阻断。
