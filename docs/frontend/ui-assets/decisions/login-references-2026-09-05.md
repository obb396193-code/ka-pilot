## 结论

1. **大厂两派**：工具类（Figma/Linear）极简居中；投放/营销平台（巨量/千川/磁力/Stripe）**一张高质量品牌视觉图撑全场 + 浮卡**。老板定的是后者的气质。
2. 图的来源是设计团队做的 3D 渲染，不是前端代码画的。我们没有设计资源 → **老板用生图工具出图**（brief 在下面），前端先用 Unsplash 免费 3D 渲染图占位，标「示例图」。
3. 代码能做、且能达到「大厂感」的补充手段：WebGL 材质动效（液态金属丝带 ≈ 磁力金牛的丝带、光谱渐变 ≈ Stripe 的笔刷、可交互光球）。用 React Bits 官方件，不自写 shader。
