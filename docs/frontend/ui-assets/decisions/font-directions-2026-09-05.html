你在 Mac 上看不出差别，是因为「X + 系统中文」在 Mac 上都是苹方在显示。差别只在两处：一是英文和数字的字形（Geist 还是中文字体自带的英文），二是到了 Windows 上中文变成微软雅黑还是仍旧是我们自己带的字体。要「Windows 上也不回退」，中文必须自带字体文件（按字切片、用到哪片下哪片）。下面每一版都真实加载了对应字体，F1 之外的四版在 Windows 上和这里看到的一致。

F1

Geist + 系统中文（现状）

Mac 上是苹方；Windows 会变成微软雅黑。作为基准放这里。

F2

Geist + Noto Sans SC

思源黑体的 Google 版，OFL 许可最干净，切片方案成熟。

F3

Geist + MiSans（推荐）

英文数字 Geist，中文 MiSans。屏幕显示最匀、最现代，和 shadcn 的气质最接近。

F4

全套 MiSans

中英数字一个家族，统一但数字没有 Geist 挺拔。

F5

Geist + HarmonyOS Sans SC

效果接近 F3；文件未切片、许可要核，工程成本更高。

F6

Mac 苹方 / Windows 兜底（推荐）

字体栈：Geist → 苹方 → 兜底字体 → 微软雅黑。Mac 有苹方就停在苹方，兜底文件一个字节都不下；Windows 没苹方才用兜底。所以这一版在 Mac 上和 F1 一模一样，差别只发生在 Windows。

怎么拍板

  • 回 F1–F6 编号即可；选 F6 再顺手说 Windows 兜底用「MiSans / Noto / HarmonyOS」哪家（看最上面那段谁最像苹方）。定了之后：字体文件切片自带进 apps/web，Windows 和 Mac 一致，不依赖外网、不回退系统字体。
  • 另有一个没下载的候选：阿里巴巴普惠体 3.0（免费商用、集团内最顺理成章）。你要看的话我拉下来加一版 F6。
  • 字体和风格（A/B/C/D）是两个独立决定，互不影响。
