A

冷静黑白 · 工程感

只用黑白灰，靠字重、线和留白分层；数字全部等宽对齐。安静、耐看、不抢眼。

B

Apple 白灰暖 · D-CON

PRD 5.1 那套：白底浅灰分区、橙色只做行动点、圆角大一点、极轻阴影。体面、有格调。

C

数据感彩色 · 看板

涨跌好坏用颜色直接说，KPI 卡带迷你趋势，卡片浮起来。信息密度高，一眼读结论。

D1

shadcn 壳 + 彩色数据 · 冷色

侧栏、顶栏、卡片、字体 = 页 1 现在的 shadcn 中性灰，一点颜色不加；颜色只进图表线、迷你趋势、环比和状态。蓝 · 紫 · 青，饱和度压一档。

迷你趋势线是示意：正式版只在后端有日序列的指标上显示（现在只有消耗和 CPA 有），其余卡等数据到了再出现，不画假线。右上角「切到黑白」可看同一页的黑白预设。

D2

shadcn 壳 + 彩色数据 · 暖色

同样的壳，数据换成橙 · 红棕 · 芥黄，延续 PRD 里 D-CON 的橙。留意橙色主线和黄色预警、红色 P0 之间是否打架。

怎么拍板

  • 直接回 A / B / C；或者混搭，例如「B 的颜色 + A 的密度 + C 的 KPI 卡」。
  • 也可以只说感受：「太花」「太素」「数字要更大」「卡片太圆」，我按感受改一版再看。
  • 定了之后写进 docs/frontend/ui-assets/decisions/，页 1 立刻按该版重刷，后面每页都按它来，不再问。
  • D 版的「黑白」只是同一套组件换一组调色板：装饰色（区分序列）退成黑灰，表含义的红绿黄保留。要做成用户可切换的设置项也是这一个开关。
  • 字体是独立决定：这里 A/C 用 Geist、B 用系统苹方，7 套字体的对比页另开了标签。
