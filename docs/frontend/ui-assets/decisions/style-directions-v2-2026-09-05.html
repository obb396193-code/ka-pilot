三个页面是同一套组件、同一份内容，只换一组变量。每个页面右上角都有主题开关，点一下当场换，这就是正式版里的切换方式（不进设置）。黑白版是真黑真白，灰只做发丝线；黑白+彩只给数据上色；全彩连按钮、选中态、页面底色一起上色。旁边的色点是色卡，换主色。

每个页面右上角两个开关：「黑白 / 黑白+彩 / 全彩」三段 = 颜色用到哪一步；旁边的色点 = 色卡，选主色（蓝 靛 紫 青 绿 橙 玫红 石墨），图表、点缀、按钮跟着变。 主色用在哪：黑白·点彩 → 只有图表第二条线｜黑白+彩 → 图表三条线 + KPI 迷你趋势｜全彩 → 再加按钮、选中态、logo。红绿黄是状态含义，永远不变。换色时会变的地方闪一下黄框。

默认主色候选（点一个，下面第 1 版页面立刻换成它）

1

黑白 · 点彩 推荐默认

你发的那张表的感觉：底子真黑真白，灰只剩发丝线；颜色只做点染——chip 里一粒色点、图表第二条线一个点缀色、红绿黄只表状态。

2

黑白 + 彩

壳和 1 完全一样；只有图表线、迷你趋势、进度条上了色。你说的「壳是 shadcn、看板偏彩」就是它。

3

全彩

改成单色系：只用一个主色加中性色，按钮实色、页底几乎不染、卡片白、阴影软、图表同色相深浅两条线。质感来自克制，不来自颜色多。换主色看色卡。

怎么拍板

  • 三版都是正式版会有的主题，你定哪个是打开默认的（另两个用户点右上角自己切）。回 1 / 2 / 3 即可。
  • 主色：弹层里 12 个预设（6×2 放得下），或在取色面板自己调、用吸管吸屏幕颜色。正式版取色器用 Dice UI 官方源码（老板已定），主色记在用户账号里，默认给全员一个。
  • KPI 卡：首页用简洁 B；数据分析等页按指标自定义用 C 的迷你趋势 / 考核线 / 分段条 / 进度条，正式版只在后端有数据的卡上显示。
  • 开关位置：现在放顶栏右上角、搜索框左边；也能放侧栏左下角用户区旁，你说一声我挪。
