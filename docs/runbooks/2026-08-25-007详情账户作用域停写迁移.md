# 007 详情账户作用域停写迁移

`007_detail_account_scope` 会为 `work_items`、`changesets` 回填账户媒体作用域、验证复合外键并建立索引。它不是在线无锁迁移。

## 执行门

1. 仅在首次启动前或明确停写维护窗口执行；暂停会写 `work_items/changesets` 的 Worker/API。
2. 执行前确认 006 已成功，并核查所有非空账户引用在同 workspace 下只能匹配一个 media；歧义或孤儿数据必须先治理，禁止默认猜媒体。
3. 007 自带 `lock_timeout=5s`、`statement_timeout=5min`；单独补跑也必须在无法及时取锁时失败退出。
4. 迁移失败保持应用停写，保留错误证据；不得跳过约束后启动服务。
5. 成功后验证两个复合外键、两个 pair check 和两个 account-scope 索引存在，再恢复只读 API/Worker。

## 回滚

只允许在确认新列尚未被后续版本依赖的维护窗口执行 down。down 同样带锁和语句超时；超时即停止，不反复盲重试。
