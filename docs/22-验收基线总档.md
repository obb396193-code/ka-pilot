# 验收基线总档（开发完成后逐条对验的唯一母档）

> 建立：2026-08-18（PRD v1.6 冻结日）　状态：❄️ 与 PRD v1.6 同步冻结
> **用途（老板原话）**：一开始的设想功能 + 对话中要加的东西 + 要设计成什么样子——开发完之后对应去看这些功能都有没有做出来。
> **验收纪律**（继承 14 号基线）：设计写了≠做出来；原型画了≠能操作；接口存在≠已接入；Agent 能答≠稳定能力。每批开发验收时回填状态列，冲突单列老板裁决，不偷改基线。

## 1. 冻结时的关键拍板存照（验收时的"原意"依据）

**产品定位**：KA 部门投放经营工作台，北极星=考核达标（真实 CPA vs 考核价），四角色（优化师/运营/负责人/高层），demo 期老板+2-5 同事。
**一级导航（终版九项）**：工作台｜投放任务｜数据分析｜账户资源｜自动化｜商品素材｜报告｜知识库｜**集成与通知**（终版命名，一期钉钉唯一重点渠道）＋头像菜单（设置/治理后台）＋⌘K Agent 抽屉。
**架构**：三 FaaS 应用（Web-API / Worker-Scheduler / DingTalk-Gateway）+ 共享网络 PG + packages/contract·db·domain。
**凭证**：每用户三凭证自持（奇航 userId / Multica mul_ PAT / IdeaLab AK，Secret 服务存 reference）；后台任务凭证归属固化、重试用原凭证、失效进 blocked_auth。
**Agent**：Claude Agent SDK 单运行时 + Provider Capability Matrix（IdeaLab 起步，Claude 双通道均可）。
**红线**：agent 不算数｜个人行为数据零上行（禁入可导出报表）｜不做个人排名｜数据不新鲜禁写｜提审/申请充值=自愿协作永非门槛｜不借他人 token。
