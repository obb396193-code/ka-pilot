可复用方法

方法一句话
内网 agent 当传感器只读探针贴原始输出，证据分五级，设计只引用前三级
契约唯一出口schema/api/metrics 冻结，谁都不发明字段和端点
信箱 + 台账 + SHA 审计派活写对方 inbox，交付 SHA 逐条 ✅/❌
agent 不算数指标全在 domain 纯函数，前端和 Agent 只展示
先不变量后逐行积压交付先按簇核不变量，再随新交付逐行 diff
视觉先小样再 commit被否整颗回退不辩护
