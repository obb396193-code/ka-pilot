# R010a1 分时累计投影（P130）

## 范围与依据

复用 `operational-query-rows.ts` 已有 account.hourly/v1，不重复定义公开 DTO。
依据 Contract api §3.5 / metrics 的累计、小时速度、时间占比公式。
本批为严格 Domain 计算边界，不宣称完成 Registry、真实 reader 或 HTTP。

1. TDD：批准 workspace+media+account 清单、同日累计观察、选中小时与前驱。
2. 输出每个请求 tuple×hour 一行；缺观察输出 missing，不能以别的媒体/日期补洞。
3. hh0 以累计零起点作差；1..23 仅和同 tuple 前一小时作差；24 为全天，不制造第25小时差值。
4. 负差值属于来源修正，保留 cumulative，delta=error，不能夹成0。缺失与错误传播分开。
5. 比率复用 finite/infinite/undefined。现金累计由受信 reader 按有效系数/补偿给出，本层不默认系数。
6. 速度仅在 reader 能证明该差值覆盖完整一小时的情况下计算；日预估仅用 reader 给出的真实已过时间占比。缺时间证据不由 hh/响应时间伪造。
7. 非法值、未知字段、重复观察/授权 tuple、越权/跨日行、超10k请求/观察均拒绝；不改变会话认证和媒体写边界。

## 后续依赖
