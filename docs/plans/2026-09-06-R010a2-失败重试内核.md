# 变更集失败重试 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 按信箱12.7/P006接failed→retry→confirmed，并复用TTL/成功预检/当前from复核，确保后续begin产生下一实际attempt。

**Architecture:** confirm/retry共用父行锁和批准状态校验；retry仅failed或可证明重试回放的confirmed，要求已完成failed的非dry-run记录和原confirm_hash；成功复核后重置item状态到pending，保留旧execution_run。TTL过期的failed不覆盖其失败终态，返回expired。没有HTTP/队列/媒体接线。

**Tech Stack:** TypeScript、pg、Domain状态机、Vitest。
