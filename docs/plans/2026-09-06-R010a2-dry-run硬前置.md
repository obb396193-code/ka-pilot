# 变更集 dry-run 硬前置 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 按P006保存预检结果并在confirm/beginExecution检查同草稿成功dry-run，阻止无预检、变值、变TTL放行。

**Architecture:** prepareDryRun读取已授权草稿及DB原始UTC微秒TTL生成hash；外部只读预检在事务外完成；recordDryRun在父行锁内核对同hash、完整item结果，再写dry_run=true执行记录和头hash。confirm重算hash+成功证据+当前值复核并写confirm_hash；beginExecution再次检查两hash和成功证据。全程无自动假预检、无写HTTP、无真实媒体调用。

**Tech Stack:** TypeScript、pg、现有Domain typed值/SHA256、Vitest。
