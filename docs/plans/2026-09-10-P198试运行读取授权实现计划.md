# P198 Preflight Read Authorization Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 收口P178真实HTTP试运行读取仍走后台通路的漏接，做到无账户授权不读取ChangeSet正文/明细。

**Architecture:** 用户/arch已批准P178共享授权方案；Service初读传approved auth，复用已有find三参RR/RO先授权分支；prepareDryRun增加可选内部auth参数，公开Service必须传，在锁定来源的SELECT中直接使用accountScopeClause。旧一参后台调用仍保留，不开启新媒体能力。三种方案中，读后拒绝不满足P178；另建权限实现会漂移；采用现有共享谓词最小接线。

**Tech Stack:** TypeScript、pg、Vitest、既有accountScopeParams/accountScopeClause。

---

采用writing-plans拆步骤；不是新产品设计，不要求老板重批已冻结授权矩阵。executing-plans技能不可用，按用户持续授权当前会话直接TDD，不新开Agent。

## Task 2 最小实现
