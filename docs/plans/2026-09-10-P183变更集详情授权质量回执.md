# P183 变更集详情授权质量回执

## 代码与边界

代码 **8db53852**。ReadDetailService 的 ChangeSetDetailPort 必须携带 ApprovedWorkspaceAuthContext 第三参；真实 PG HTTP spy 包装同步透传。
ChangeSetRepository 三参find进入会话专用路径，显式undefined也拒绝，不回落内部路径：

1. 严格personal auth/workspace匹配，否则连接前拒绝。
2. 同一RR/RO事务仅SELECT id/workspace/共享谓词计算的allowed，不读取title/simulation/items。
3. 不存在返回null供HTTP404；同空间未授权抛固定ChangeSetAuthorizationError供HTTP403。
4. 通过后完整header仍带共享谓词，items沿既有header三键校验；Service后置ID/tuple/strict response guard保留。

后台原两参find仍存在，供内部执行/回收入口；不是新增浏览器路径。公开Service端口第三参必填且生产实际传入；今后其他包装器不得遗漏它。
本批不伪造会话供后台job，不开放媒体写或team变更集，不更改公开DTO。
旧HTTP已有Service过滤，本轮是SQL授权前置，不冒称修复已证实对外泄漏。
