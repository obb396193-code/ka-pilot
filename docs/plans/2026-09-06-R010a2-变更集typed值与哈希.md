# 变更集 typed value 与哈希 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 落实api.md v1.3/P006的类型化修改值、严格比较和dry-run哈希，为替换旧字符串Repository做好同一个可复用内核。

**Architecture:** 新Domain模块解析number/boolean/string/json/schedule168联合类型，canonical JSON按键排序、数组保序；按目标类型/ID/字段稳定排序条目，拒重复目标字段；sha256(canonical_json(sorted snake_case items)+原样合法TTL字符串)。不得转Date丢失微秒；持久化/读取须共用同一TTL表示。尚不替换旧执行通路，下一批接Repository与HTTP时统一使用，不允许新旧混执行。

**Tech Stack:** TypeScript、zod、Node crypto、Vitest。

## Task 1: 红测试

- Create `packages/domain/test/changeset-values.test.ts`，Modify `packages/domain/src/index.ts`后续导出。
- number≠string≠boolean；json对象键序不影响等价、数组序有意义；拒NaN/Infinity/undefined/Date/cycle/accessor/sparse array；schedule168仅168个01，media_default只能true。
- hash顺序无关、from/to/field/target/TTL变化必变、重复目标字段拒绝、微秒TTL不丢失；原输入不修改；固定SHA对照Node独立公式。
- `npm --prefix packages/domain test -- --run changeset-values.test.ts`先应因模块缺失失败。

## Task 2: 最小内核

- Create `packages/domain/src/changeset-values.ts`。schema strict、JSON无隐式stringify/toJSON/coercion；受控深度/节点数保护避免递归崩溃。所有JSON属性必须普通enumerable data property，无symbol/访问器。只处理JSON DTO，不调用任意对象方法。
- `sameChangeValue(left,right)`比较类型与canonical值，包括media_default标记；`hashChangeSetDraft({items,ttlExpireAt})`只接受明确snake_case目标字段，不收备注/工作区/用户输入URL。
- 预算：最大深度64、JSON节点10000、序列化有效载荷16MB；是内部资源护栏，不声称媒体接口业务上限。公共HTTP已有1MB请求限额不得提高。

## Task 3: 检验/交接

- Domain定向/全量/typecheck/lint、Worker回归/typecheck、DB typecheck；覆盖>80%、offline audit、敏感输出/性能审计。
- 与arch changesets/detail fixture的fromValue/toValue逐项schema对照；fixture哈希本身是示例，不假称实算金样，首次持久化前需arch核对canonical编码约定。
- 本批不更改旧字符串执行器、旧DB JSON桥或HTTP，因此不能宣称typed链路/confirm闭环已实现。无媒体写/迁移/真实源/推送。
