# 前端规范实验室 Demo 设计

> 日期：2026-08-20
> 状态：老板已确认做独立临时离线 Demo；只用于看效果和调整规范，不代表最终产品视觉拍板。

## 目的

把文字、数字、布局、密度、主题和动画规范从文档变成可操作页面。老板可以现场切换主题、字号、密度和 motion 模式，比较“合适/不合适”用法，再决定哪些 token 进入真实产品。

## 方向

采用“精密数据标本室”风格：暖纸色工作台、深墨控制栏、钴蓝主信号和朱红风险提示，结合细网格、标尺、序号和排版样张。它不是最终品牌皮肤，而是让层级、数字对齐和动画差异更容易观察的中性实验环境。

## 结构

1. **全局控制台**：主题、密度、字号、动画正常/减弱/关闭、重播动画。
2. **字体标本**：页面标题、区块标题、正文、标签、辅助文字、长中文和英文数字串。
3. **数字格式实验**：金额、百分比、CPA、万/亿缩写、精确 tooltip、0/null/stale、tabular nums 与错误对齐对比。
4. **数据工作台样张**：KPI、筛选、趋势证据、表格、状态和下一步动作，体现信息层级与留白。
5. **布局与密度**：同一组件在 compact/default/comfortable 和桌面/移动容器中的变化。
6. **文字/数字 Motion Lab**：Typing、Morph、Roll、Scramble、Shimmer、Loop、Animated/Sliding/Counting Number；每种注明适用与禁用场景。
7. **官方来源窗口**：嵌入现有 Motion Primitives 与 Animate UI 离线官方源码 frame，明确和规范演示的区别。
8. **Storybook / ECharts / UI 展厅**：用三个并排工作台说明职责差异；ECharts 区用无依赖 SVG 只展示图表视觉规范，正式产品仍由 ECharts 实现。
9. **即时审核面板**：显示当前设置、硬门禁、建议项和可调整项；不把审美评分冒充自动真理。

## 技术边界

- 路径：`docs/frontend/ui-assets/standards-demo/`。
- 单文件 `index.html` + README，不安装 npm 包、不改 `apps/web`。
- 无 CDN、fetch、字体下载或服务端依赖；直接 `file://` 可打开。
- 只读嵌入已存在的两个 offline sandbox frame，不反编译第三方 bundle。
- 所有业务数据为显式脱敏假数据。
- 实际 responsive 同时用 1440 和 390 浏览器测试；页面内部 viewport 控件仅用于快速比较。

## 可调整原则

- 字体、字号、间距、圆角、色彩、动效参数都通过 CSS variables 控制。
- Demo 提供推荐起点，不写“必须最终长这样”。
- 老板觉得某种组合不好看时，直接切换验证；最终选择再回写 token/decision。
- 动效关闭后信息完整，文字和数字保持真实可访问内容。

## 验收

- 直接双击可打开，无外部请求和 console error。
- 主题/密度/字号/motion 控制均有可见效果。
- 7 种文字动画、3 种数字动画可重播；reduced/off 生效。
- 金额、百分比、CPA、日期、单位、大数和 null/stale 状态齐全。
- 1440 与 390 无横向溢出，键盘焦点可见。
- 页面明确标注“临时规范实验，不是最终产品皮肤”。
