# 变更集 typed value 纵向接线 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将P006已冻结五类型值接入既有Domain比较/反向草稿、JSONB Repository、Worker复核与只读详情，停止新草稿写入字符串桥。

**Architecture:** 复用61abbcf的changeValueSchema与sameChangeValue；只接受typed输入，JSONB直接存严格对象。遗留字符串/null和present-invalid输出拒绝而不猜类型、不改数据；重新生成草稿的业务入口仍待后续HTTP批。所有身份/三键守卫保留。

**Tech Stack:** TypeScript、zod、pg、Vitest。

现有arch P006明确要求typed JSONB，不是新设计。executing-plans技能不可用，主agent按TDD实施；不派子agent，不改Contract。

- 新增`packages/db/src/changeset-item-values.ts`集中JSONB编解码，验证后同步固定JSON字符串再await，避免调用方异步修改已验证对象（质检红测试复现）。
- 更新现有Domain/DB/Worker测试的合成输入为typed，剔除旧“新建字符串桥”happy path，新增遗留读拒绝。Worker ports类型跟随唯一Domain。
