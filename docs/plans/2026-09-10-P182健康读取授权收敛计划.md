# P182 健康读取授权收敛 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 落实 arch P-178 的健康概览读取共享授权谓词要求，同时保留未同步授权账户的缺数分母。

**Architecture:** 在 RR/RO 查询中形成当前 workspace 主账户与受信授权账户的候选并集，统一经 accountScopeClause 收口后再关联指标。个人空 grant 返回空，team 仅当前 workspace；SQL 后原计数/时间校验不删。

**Tech Stack:** TypeScript、Vitest、PostgreSQL、现有 ApprovedWorkspaceAuthContext 和 r014 共享谓词。

## Task 2：共享收口

文件：`packages/db/src/platform-health-repository.ts`。

候选为 `accounts WHERE workspace_id=$1 UNION jsonb_to_recordset($4)`，按三键约束关联 metric；`WHERE ${accountScopeClause("$3", "$4", "candidate.media", "candidate.account_id")}`。
参数 `$3/$4` 改用 `accountScopeParams(auth)` 的 kind/allowed，而非另拼 workspaceKind。UNION 去重，未知主账户授权仍保留。
生产不删除谓词、不修改公开 DTO、session 或 team 私人工作项规则。
