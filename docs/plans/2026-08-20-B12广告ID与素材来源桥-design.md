# B12 广告 ID 与素材来源桥设计

> 状态：老板已于 2026-08-20 选择方案 A；本文描述内部后端设计，不代表已部署或已完成真实通路验证。

## 1. 目标

在不修改公开 API、数据库契约和前端的前提下，补齐两个底层来源能力：

1. 为单账户 `ad_realtime` 恰好命中 2000 行时准备权威广告 ID 拆分种子；
2. 为后续素材拆片提供可分页、可校验、可追踪的视频来源候选。

本批只建立来源桥和安全门，不实现视频物理下载、拆片分析、Prompt 调用或前端素材页。

## 2. 已确认事实与未确认边界

### 已确认

- `kuaishou-cli unit list` 调用 `gw/dsp/unit/list`，支持 `advertiser_id/page/page_size`，现有 CLI 内部已有翻页枚举 `unit_id` 的实现。
- `qihang-cli material list/list-all` 调用 dataservice-api 的素材池只读 GET；单页最大 500，响应提供 `rows/totalNum/pageNum/pageSize`。
- 素材池行可包含 `signature/material_name/material_type/item_id/material_url/poster_url/pict_url/width/height/inventory_name/material_spec_name`。
- B11 已证实无过滤 `ad_realtime` 会在 2000 行静默截断，分页参数无效。

### 未确认

- `unit_id` 是否与 `ad_realtime.ad_id` 同一标识；确认前禁止把 unit 列表作为广告 ID 拆分种子。
- 素材 `material_url` 的协议、有效期、响应类型、大小和本项目 Worker/FaaS 网络可达性。
- 产品身份能否直接调用快手 MAPI 对象清单；现有真实 token 由 OS/Multica 沙箱代理注入，不能假设产品服务拥有该权限。

## 3. 设计

### 3.1 广告 ID 证据门

新增内部 `AdIdentifierDiscovery` 模型，显式携带：

- 来源类型；
- 标识列表；
- 完整性 `complete|unknown`；
- 与 `ad_realtime.ad_id` 的映射状态 `confirmed_equal|unverified|not_equal`；
- 不含真实业务 ID 的证据摘要。

只有 `complete + confirmed_equal` 可以经 `requireAuthoritativeAdIds` 转成 B11 可用的 `adIds`。任何未确认或冲突状态稳定 fail-closed。候选适配器可以先解析 OS/CLI 的结构化 unit 列表，但不会因此自动获得权威资格。

### 3.2 素材池客户端

新增独立 `MaterialPoolClient`，只支持只读 GET：

- 显式要求媒体、素材库 ID 和商品 ID 选择；
- 页大小限定 1..500；
- `listAll` 有最大页数、最大行数和最大响应字节预算；
- 校验业务 envelope、页码、页大小、total 稳定性和分页进度；
- 以 `signature` 为稳定键去重；同键不同内容立即失败；
- 不在错误、日志和观测里回显完整 URL、商品 ID 或素材 ID。

### 3.3 视频来源安全门

素材行首先归一化为候选，而不是“可下载文件”。候选要进入后续拆片至少满足：

1. `material_type` 是视频；
2. URL 为 HTTP(S)，不含用户名密码和 fragment；
3. host 命中部署环境显式 allowlist；默认空 allowlist 即全部阻断；
4. HEAD 或最小 Range 探针确认最终跳转链每一跳仍在 allowlist；
5. Content-Type 为允许的视频类型，Content-Length 未超过配置上限。

本批可实现探针和准入结果，但不把视频正文写盘。

## 4. 错误与观测

- 对外只暴露稳定错误码：`UNVERIFIED_ID_SOURCE`、`MATERIAL_PROTOCOL_ERROR`、`MATERIAL_RESOURCE_LIMIT`、`MATERIAL_SOURCE_BLOCKED`。
- 观测只记录资源、页数、行数、去重数、指纹、阻断原因枚举和时间；不得记录完整 URL、真实 ID 或响应正文。
- 网络 502/503/504 可有界重试；业务错误、Schema 漂移、资源超限和安全阻断不重试。

## 5. 接线边界

- B12 先作为 Worker 内部模块和端口存在，不新增公开 DTO、数据库 migration 或 job type。
- B11 仍保持单账户 2000 行 fail-closed；只有 OS 实证确认 ID 映射后，才单独接入自动 adIds 拆分。
- 拆片能力下一批复用 ContentRadar 的结构化拆解方法和本地拆片提示词；B12 只交付可靠视频来源候选。

## 6. 验收

- 权威 ID 门对所有未确认状态拒绝，确认且完整时稳定去重输出。
- 素材分页在 total 漂移、空页未完成、重复冲突、超页/超行/超字节时 fail-closed。
- URL 准入默认拒绝，显式 allowlist 后才允许探针；跳转逃逸、未知长度、超大文件和非视频均阻断。
- 单元测试、typecheck、lint、audit、复杂度和敏感信息扫描通过。
