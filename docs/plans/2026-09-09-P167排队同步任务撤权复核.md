# P167 排队同步任务撤权复核 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 已排队或重试的 scheduled ETL 在取凭证前，必须确认冻结账户仍全部获授，撤权则 blocked_auth。

**Architecture:** withQihangIdentity 把校验后的冻结 tuple 范围传给 CredentialRepository，同一 SQL 验证 active personal workspace/user/member/identity 及每个未撤销 grant 后才返回奇航身份。不缩范围、不换 owner、不 fallback；handler执行前保留私有payload副本，避免await期间上下文被改。

**Tech Stack:** 现有 TypeScript/Domain schema/pg/Vitest，不改数据库DDL、公开DTO或媒体操作。
