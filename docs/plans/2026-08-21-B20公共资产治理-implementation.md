# B20 公共资产治理领域底座实施计划

## Task 1：严格版本模型

- 先写失败测试：资产类型、版本号、适用范围、依赖、来源、时间和定义指纹。
- 实现创建不可变 draft 版本、稳定排序、深冻结与稳定指纹。
- 拒绝自依赖、重复依赖、非法来源和非规范时间。

## Task 2：验证记录和生命周期

- 先写失败测试：严格五段流转、越级失败、事件幂等/冲突。
- verified 必须有绑定当前定义指纹的最新 passed 验证。
- deprecated 必须有原因，替代版本不得指向自身。

## Task 3：使用聚合和统一摘要

- 先写失败测试：使用事实幂等/冲突、用户去重、频次、最近使用时间。
- 输出完整 REQ-114 元数据和稳定 fingerprint。
- 重算输入完整性，防止只替换外层 hash 的篡改。

## Task 4：质量与交接

- Domain 定向/全量 test、coverage、typecheck、lint。
- 全仓默认回归、audit、复杂度、安全和冻结目录检查。
- 更新状态、总账、工作台账并新增 arch 审查项 P-027。
