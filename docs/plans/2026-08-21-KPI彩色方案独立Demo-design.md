# KPI 彩色方案独立 Demo 设计

> 日期：2026-08-21  
> 状态：老板已确认  
> 边界：仅新增独立 Demo，不修改现有 `sidebar.html`、`topbar.html` 或产品前端。

## 目标

在同一组脱敏投放数据下，对比 shadcn 中性原版、克制业务色、较强驾驶舱色三种 KPI 表达，帮助判断正式前端是否需要增加颜色，以及颜色应增加到什么程度。

## 方案

独立入口为 `apps/ui-layout-demo/kpi-color-demo.html`。页面提供 A/B/C 三档切换：

- A 中性原版：白、黑、灰作为评估基线。
- B 克制业务色（默认推荐）：蓝色表达主指标，绿色表达正常，琥珀色表达观察，红色只表达异常。
- C 驾驶舱色：提高渐变、色块和趋势线的存在感，用于判断强色是否过度。

卡片采用成熟数据看板结构：今日消耗为主卡，含迷你趋势；真实转化与活跃账户为紧凑 KPI；成本达成率使用目标线和进度条。基础 Card、Badge、Button 和 Tooltip 继续使用项目已隔离的 shadcn new-york-v4 源码；趋势与指标表达参考 shadcn Chart 和 Tremor KPI/Data Bars 模式。

## 隔离要求

- 不修改现有入口和组件。
- Demo 样式全部放在 `.kpi-color-demo` 作用域内。
- 不向现有 `shadcn.css` 增加规则，只读取其字体和 token。
- 使用脱敏假数据，并在页面标明。
- 新建独立 Vite 构建配置，验证 Demo 时不改变原构建输入。

## 验收

- A/B/C 可通过按钮和键盘切换，当前选择对辅助技术可识别。
- 1440×900 无横向溢出；数字采用 `tabular-nums`。
- 页面不请求远程字体、图片或 CDN。
- 单元测试覆盖三种模式、默认模式、主要指标和隔离入口。
- 原侧栏与顶栏测试继续通过。
