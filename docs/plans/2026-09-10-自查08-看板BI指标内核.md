# 看板 BI 指标 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 按 v1.9.22 给 P211 提供统一三 BI 指标计算，避免 UI 或两数据源各写一份算法。

**Architecture:** 仅新增纯 Domain 模块，接收经授权仓储提供的完整 expected account-day 集合；按 history / ka_daily 判别价格证据，调用已有 computeWindowAssessment / computeKaDailyWindowAssessment。bi_conv=sum(realConversion)，bi_cash_cost=divideMetricValues(sum cash, sum BI)，over_cost=-costSpace。不改查询信封，不声称本函数证明数据范围或完整性。

**Tech Stack:** TypeScript、Zod、Vitest；复用 MetricValue / RatioValue / 窗口考核算法。
