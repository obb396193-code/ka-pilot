# R010a1 透视任务筛选 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> 子技能不可用，按已授权连续队列本地执行，不派子会话。

**Goal:** 将已冻pivot2.taskIds从拒绝参数变为真实账户每日任务归属筛选，跨日换任务不串数。

**Architecture:** 复用已验证的完整RR账户日快照和Domain投影守卫，先验证所有成员（含随后被筛掉者）再筛选、重新按两维汇总。不是先聚合账户总量再过滤任务标签。source lineage仍描述完整已授权读取窗口，cellCoverage只描述筛选后的格子；即使不相关任务缺数也保留保守的source partial，不伪造完整数据。

**Tech Stack:** TypeScript、Zod、Vitest、PostgreSQL。
