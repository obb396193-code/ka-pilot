## 当前安全边界

- 真实投放视频帧尚未获准发送到一个明确的受信任多模态 Provider，因此 Agent 当前只接收字幕、Shot 时间边界和确定性统计；状态固定为 `blocked_pending_trusted_multimodal_provider`，不得假装看过图片。
- `CloudAsrPort` 只是可替换端口，尚无具体供应商适配器或真实 API Key 联调。
- checkpoint 目前是内部端口；没有 DB 实现、正式 Job、公开 API 或生产 Runtime 注册。
- 当前临时帧随素材句柄释放。未来开放视觉分析前，必须同时增加受控持久 artifact checkpoint、保留期和删除策略。
- 尚未用产品 Worker/FaaS 对真实素材 CDN 执行下载和拆片；OS 的沙箱实证不能冒充产品部署实证。
