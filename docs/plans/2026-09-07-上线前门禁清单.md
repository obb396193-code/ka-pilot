- **A31**（2026-09-10）：前端 `as unknown as Fixture<…>` 一律禁止——会把契约的可选字段/判别联合压平，运行时 `undefined.value` 整页崩（盯盘页、F8-19 各撞一次）。带 `type`/`kind` 判别键或可选字段的形照 zod schema 抄成联合/可选，让编译器指出要兜的地方。

- **A32**（2026-09-10）：`runtimeDataClient()` 在 mock + production build 下会抛「Mock provider is disabled in production」，任何在 mock 分支也会执行的取数代码都不得调用它——只在真实模式分支里建客户端（fe F8-19b ① 踩坑）。

- **A33**（2026-09-10）：`packages/domain` 禁循环 import（A 调 B、B 又调 A）——vitest 全绿也可能假绿，真 CLI 入口直接 `ReferenceError: Cannot access … before initialization`（be2 Q-041 ② 撞到，只有 db 包三条起真子进程的用例 `seed-bootstrap / seed-coefficients / qihang-identity-seed` 抓到）。纯算术/常量拆独立模块并注明不许反向 import；domain 有改动的交付，门禁跑全量 db 包（含那三条）不许 PKGS 跳过。

- **A34**（2026-09-11，OS 建议）：env 键差集门禁——扫代码实际读取的环境变量键（同时扫 `process.env.X` 与 BFF 的 `environment.X` 两种写法）与部署方 `runtime.env`/`.env.example` 键集合做差集；内网 `KA_DATA_SERVICE_TOKEN` 漏配导致登录 503，症状与根因隔两层。be2 出脚本进 CI（P2）。
