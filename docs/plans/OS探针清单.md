# OS 平台探针清单

> 用途：直接复制发给 OS 平台上那个 agent，让它**实际跑命令**回答，不要它推测。
> 回答拿到后贴回来，我更新 `docs/02-技术侧现状.md` 并记台账。
> 原则：全部只读探测，不碰任何写操作。

## 探针 1（最高优先）kuaishou-cli 凭证来源

```
只做只读探测，不要执行任何写操作。请实际跑命令而不是推测，把命令和原始输出一并贴出来：

1. kuaishou-cli 这个二进制在哪（which kuaishou-cli / ls -l 结果），版本号是什么。
2. 它的鉴权凭证从哪来：是沙箱环境变量注入（把相关变量名列出来，值打码），还是本地配置文件（路径 + 字段名，值打码），还是要用户自己登录（登录命令是什么）。
3. kuaishou-cli --help 的完整输出，以及任意一个子命令的 --help。
4. 关键问题：如果把这个二进制拷到沙箱外的一台普通机器上，用我自己的快手账号/MAPI 凭证，它能不能跑通一条只读命令？依赖哪些环境变量或内网域名？请给出判断依据，不要只给结论。
```

## 探针 2 BI 真实转化的通路

```
只读探测，请实际跑命令并贴原始输出：

1. 现在能查"后台真实转化"（BI 口径，不是媒体账面转化）的 skill 有哪些？把它们的 SKILL.md 全文贴出来。
2. 这些 skill 底层调什么：CLI、HTTP 接口、还是数仓查询？鉴权怎么来的（变量名/配置路径，值打码）？
3. FBI 平台能不能从这里查？用什么方式（CLI / MCP / 接口）？需要什么权限，我这种业务侧账号默认有没有？
4. 能拿到的 BI 指标有哪些字段、最细到哪个维度（账户？计划？任务？）、能回溯多少天？
```

## 探针 5 kuaishou-cli 只读能力边界

```
只读探测。我要判断能拿到多少数据来做分析，请给出：

1. 所有只读子命令的完整清单（account / campaign / unit / creative / report 等），每个的参数说明。
2. 报表类命令能拿到哪些指标字段（曝光/点击/消耗/转化/CTR/CPC/CPM…），完整字段名列表。
3. 支持哪些维度拆分（日期/账户/计划/单元/创意/资源位/出价方式/客户端…）。
4. 时间粒度（小时？天？）和历史回溯上限。
5. 单次请求的条数上限、频控限制。
6. 实际跑一条 report 命令，把返回的 JSON 结构（字段名保留，数值可打码）贴出来。
```
