- 验证：domain 新增 15 tests；Worker Agent 2 tests；两包 typecheck/lint 全绿。

### Task 2：严格工作流 DAG 编译

- `b7-internal-v1` graph 与 `b7-params-v1` 参数信封采用 strict Zod 解析。
- 固定节点/边上限、精确 capability 版本、kind 一致性、输入字段、参数和上游输出绑定。
- 首版只允许 DAG；拒绝环路、自环、孤岛、重复依赖和未知端点。
- React Flow 的位置/标签仅用于展示，剔除后再生成稳定 SHA-256 执行指纹。

- 验证：domain 新增 19 tests；focused test、typecheck、lint 全绿。

### Task 3：事件回放与运行状态机

- 严格版本化事件覆盖 run/node 启动、成功、重试等待、确认等待、确认恢复、暂停、跳过、失败、UNKNOWN 和终态。
- 每 Run sequence 必须从 1 连续递增，时间不可倒退，非法状态跃迁 fail-closed。
- Runner 可从事件重建节点状态；成功节点在 lease 重入后不会重跑。
- retry 受 capability 最大尝试约束；execute UNKNOWN 直接成为终态，不进入普通 retry。
- 确认必须匹配 preview hash 且未过期；确认后以同一 attempt 进入 execute phase。
- 节点幂等键绑定 run/node/attempt/capability version/input hash。
- 验证：domain 新增 6 组状态机 tests；domain 全量 150 tests、typecheck、lint 全绿。

### Task 4：PostgreSQL Workflow Repository

- 使用现有 definitions/versions/runs/run_events 四表，未改契约或迁移。
- definition/version/run 全链按 workspace 联表校验；发起人与凭证所有者必须属于同一 workspace。
- definition 行锁串行分配版本号；发布以“调用方已验证的 graph/params 快照”事务比较，published 后 Repository 不再允许修改。
- Run 只绑定 exact published version，冻结 initiator、credential owner 和 params。
- event append 以 Run 行锁分配连续 sequence；schema version/sequence/dedupe key 保存在现有 detail JSONB，重复键同内容返回既有事件、异内容冲突。
- JSON 输入拒绝函数、Infinity、循环和非 plain object，避免 JSON.stringify 静默擦除/变形。
- 验证：6 个专项 PostgreSQL tests；DB 全量 69 tests、typecheck、lint 全绿；迁移未改。

### Task 5：无写入工作流模拟器

- 按固定版本计划的稳定拓扑序解析参数、上游输出和 literal，每节点重新校验精确 capability 版本、权限及输入输出 Schema。
- execute 能力只调 preview，模拟返回 `would_wait_confirmation`，不可到达真实写端口。
- 缺参数、多余参数、上游失败、权限拒绝、能力漂移、输出过大/非法和超时均 fail-closed，只返回稳定错误码。
- 模拟幂等键绑定 simulation/plan/node/capability/input；输出大小在保存前校验，异常和传入秘密不进结果。
- Worker 的 Zod 从浮动 `^4.1.5` 收紧为与 Domain 一致的 `4.1.5`，消除同一 Schema 跨包的类型身份分裂。
- 验证：7 个专项 tests、Worker typecheck/lint 全绿。

### Task 6：可恢复 Durable Workflow Runner

- 事件流是运行真相；每次推进重放 exact published plan，已成功节点不重跑，崩溃留下的 running 读/preview 以原 attempt 和原幂等键恢复。
- 按稳定顺序支持线性 DAG 和 fan-in；节点开始事件在外部 effect 前持久化，输出用 `putOnce` 稳定引用供下游解引。
- read/preview 可按 capability 最大次数有界重试；错误仅保存稳定安全码。每次 advance 还有步数和墙钟上限，超限安全让出。
- execute 从技术路由上不可到达 generic invoker；必须先走 Changeset preview，以 changeset ID + preview hash 等待确认，且仅相同 hash/未过期确认可续跑。
- 确认后执行超时/歧义或写后输出无法可靠持久化时进入 UNKNOWN，禁止普通重试，保留 `reconcile/` 对账引用。
- run/credential owner/workspace 冻结校验，支持暂停、恢复、取消；凭证形态错误码、字段和输出 fail-closed，不进事件。
- 验证：Runner 10 tests + Simulation 7 tests、Worker typecheck/lint 全绿。全量 Worker 在受限沙箱中只因旧 gateway E2E 无法监听 `127.0.0.1` 失败，将在 Task 7 升权环境复验。
