# B14 第五轮实证与整段 ASR 设计

> 日期：2026-08-20
> 状态：老板已确认“先做单次整段 ASR 诊断”

## 1. 目标

在不新增公开 API、数据库迁移、生产 Job 或前端的前提下，修正 B13 的两个真实通路假设：素材 URL 是短期重签资源；IdeaLab Whisper 可用但没有时间戳。交付可替换、可测试、不会伪造时间精度的内部领域与 Worker 端口。

## 2. 方案比较与裁决

| 方案 | 调用 | 时间精度 | 代价 | 结论 |
|---|---:|---|---|---|
| 单次整段 ASR | 1 次/视频 | `whole_video` | 最低，不能逐句对镜头 | **老板选择** |
| Worker 切块 ASR | 多次/视频 | 粗时间窗 | 更慢、更贵、失败点多 | 后续可选 |
| 等原生时间戳 ASR | 1 次/视频 | segment/word | 当前不可用，会阻塞 | 不等待 |

## 3. 数据模型

### 字幕精度

`TranscriptTimeline` 与每条字幕证据增加：

```ts
type TranscriptTimingPrecision = "segment" | "whole_video";
```

- 现有平台字幕/带时间戳云输出为 `segment`；
- IdeaLab `{text}` 输出规范化为单条 `0..durationMs` 字幕，标记 `whole_video`；
- precision 进入 fingerprint、checkpoint 和 Prompt 证据，禁止同文本不同精度错误复用。

### 分析降级

当唯一字幕为 `whole_video`：

- Agent 可以做全文语义诊断；
- 不得把字幕用于证明子时间段内发生的台词；
- 时间轴输出降级为一个覆盖全片的结构段，详细镜头切分只保留确定性 Shot 数据；
- `uncertainties` 必须声明无句级时间戳。

## 4. IdeaLab 端口边界

本批不猜内部 HTTP endpoint。增加“整段文本云 ASR”适配端口：一次输入本地受控媒体文件，只接受严格 `{text}` 结果并映射为 `whole_video`。真实 IdeaLab transport、AK secret reference、multipart 字段、文件限制和计费等到取得官方/OS 请求契约后接入。

## 5. 素材 URL 租约

稳定持久化：素材来源引用、`photo_id/signature`（由未来契约裁决）、内容 SHA、自有 artifact 引用。

禁止持久化为可重试输入：完整签名 URL。

执行顺序固定为：

```text
稳定素材引用
  → OS Source Bridge 获取一次性候选 URL
  → 同一 Handler 立即执行受控下载
  → 按内容 SHA checkpoint
  → 释放 URL 与临时文件
```

失败重试重新获取 URL，不复用上次 URL。B14 只定义内部 `MaterialUrlLeasePort` 和编排测试，不发明 OS HTTP/CLI 回执协议。

## 6. 不进入本批

- 商品主数据、素材池发现、text pool 发现；
- link build 写/生成与回查；
- 承接页公开诊断 API 和手机端 Deeplink 验证；
- 真实 IdeaLab 文件调用、真实素材/FaaS E2E；
- DB/API/Job/前端、视觉帧外发、多次分块 ASR。

## 7. 验收

- 整段文本只调用一次 Cloud ASR，形成 `whole_video` 精度并进入稳定指纹；
- 带时间戳旧路径保持兼容；
- 整段字幕不能支撑伪造的多段精确分析；
- 每次下载前重新取 URL，checkpoint 和错误中都没有 URL；
- B13 全量回归、真实 FFmpeg、SDK/网关、PG 门禁继续通过；
- 第五轮事实以脱敏证据入总账，未执行项继续标未验证。
