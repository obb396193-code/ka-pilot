# UI 资产高频源码缓存与可视化展厅设计

> 日期：2026-08-19
> 状态：老板已选择方案 A（高频启动包）

## 1. 目标

在现有 12 条产品线、5,936 个逻辑资产目录之上补三件可直接使用的产物：

1. 合法缓存高概率会用到的免费源码，而不把目录元数据继续误称为源码；
2. 为付费能力建立“同品牌 Free / 其他 MIT、Apache 免费实现 / 独立业务组合”替代关系；
3. 建一个离线可打开的 HTML 展厅，让老板能看风格、能力、访问层级、免费替代和源码缓存状态。

## 2. 已确认边界

- 不绕过登录、401、License Key、会员或商业许可证，不从搬运站获取付费源码。
- 不在当前 F-001 脏工作树中安装或覆盖运行时组件；缓存放文档资产隔离目录，后续选型拍板后再接入 `apps/web`。
- current coss 与 coss Origin 分开：
  - current：577 条，Base UI 新架构，508 Particles + 69 基础/支持项，优先使用；
  - Origin：646 条，599 个 legacy `comp-*` + 47 支持项，MIT、可继续用但维护有限，只作缺口补充。
- shadcn 已有 22 个本地风格源码文件；本轮 starter pack 重点补 coss、ReUI、Tremor、Aceternity、Magic UI、React Bits 和 tweakcn 的公开源码。
- 用户已批准方案 A：缓存高频根资产与必要依赖，不镜像全部 3,709 个公开源码。

## 3. 高频源码缓存设计

目录：`docs/frontend/ui-assets/source-cache/`

```text
source-cache/
├── manifest.json              # 每个缓存资产、访问状态、license、hash、文件清单
├── README.md                  # 使用和更新规则
├── coss/                      # 官方 Registry item JSON，含源码内容
├── reui/                      # 免费 item JSON，按明确 style 固定
├── tremor/                    # 官方 raw GitHub 源文件
├── aceternity/                # 官方免费仓源文件
├── magic-ui/                  # 免费 Registry item JSON
├── react-bits/                # 免费 TS + Tailwind 变体源码
└── tweakcn/                   # 官方 presets/token 源
```

选择以投放 Agent 已冻结功能为依据，不以“看着漂亮”单独决定：

- 高频筛选：日期/范围、Combobox、Command、Select、多选、Field/Input Group；
- 数据操作：Data Grid、表格工具栏、分页、列控制、空态、Skeleton；
- 反馈与容器：Dialog、Drawer、Sheet、Popover、Tooltip、Toast；
- 数据表达：KPI 卡、趋势/报告布局、图表容器；
- AI/品牌区：Bento、少量背景/文字动效、Agent 欢迎态；
- 主题：tweakcn 官方 preset 源与 token 结构。

每项必须保存：官方 URL、获取日期、访问层级、许可证与作用域、上游 variant/ref、payload SHA-256、本地相对路径、是否根资产/传递依赖、接入状态。只有实际落盘且 hash 可复核的才标 `cached`。

## 4. 付费能力的合法免费替代

生成 `free-alternatives.json` 与 `free-alternatives.md`，按能力而不是按营销名称匹配：

1. 同品牌 Free 版本能覆盖时优先；
2. 再查现有 3,709 个 public-source 资产的 canonical capability；
3. 再研究额外高质量、许可证清楚的 React/Next.js 来源；
4. 仍无现成项时，只提出基于公开 primitive 的独立业务组合方案。

替代项标明 `exact / close / composition` 三档，避免把“功能相近”写成“完全相同”。禁止复制付费预览的独特实现细节或受保护源码。

新来源只进入 discovery 区，满足以下条件后才升级为正式全量目录：官方仓库/Registry 可追溯、许可证清楚、React 19/Next 15/Tailwind v4 适配可判断、维护状态可核验、不是纯搬运站。

## 5. HTML 展厅设计

路径：`docs/frontend/ui-assets/showcase/index.html`

技术：纯 HTML、CSS、原生 JavaScript；生成紧凑的 `showcase-data.js`，支持 `file://` 直接打开，不依赖开发服务器和线上 API。

视觉方向：编辑部式“组件情报图鉴”，米白纸张底、墨黑信息层、信号橙与状态绿；强调来源证据和工程取舍，不做紫色渐变式营销页。

页面结构：

1. 总览：5,936、公开/付费、缓存数量、覆盖不确定项；
2. 产品线地图：12 条产品线截图、风格、底层、适用/不适用场景；
3. 全量资产浏览器：按来源、访问、种类、能力和关键词过滤；
4. 同能力对比：日期、Data Grid、筛选、图表、空态、动效等横向比较；
5. 付费 → 免费：展示 exact/close/composition 替代和许可证；
6. Starter Pack：显示真正缓存的源码、依赖、SHA 与打开路径；
7. 新发现：额外好看库的真实截图/官方链接、许可证和是否值得纳入。

截图只使用官方页面的当日取证图或本地展厅截图，明确“官网预览不等于项目已接入”。

## 6. 数据流与错误处理

```text
12 份 catalog JSON
  ├─> starter selector ──> 官方公开 endpoint ──> source-cache + manifest
  ├─> paid capability mapper ──> free-alternatives
  └─> showcase builder ──> showcase-data.js + index.html
```

- 401/403：记为付费边界并停止，不重试绕过；
- 404：先核对上游重命名，再记 stale，不造假文件；
- hash 变化：必须人工复核后更新；
- license 不清：不下载源码，只保留 discovery metadata；
- 依赖递归：只跟同来源公开 Registry 依赖，设去重和循环保护；
- HTML 数据过大：只嵌入浏览必需字段，完整 upstream metadata 仍留在 catalog JSON。
