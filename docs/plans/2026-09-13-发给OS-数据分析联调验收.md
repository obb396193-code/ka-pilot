# 发给内网 OS：数据分析真数联调验收（2026-09-13）

> 仓库：`https://github.com/obb396193-code/ka-pilot`（main）。本轮**只验数据分析**；钉钉发送下一轮再验，本轮不要配出站。
> 凭证纪律不变：启航 userId、ka-data 地址与 reader token、登录密码**只进受控 env / Secret**，聊天与回执里只写「已设置」「已取到，N 字符」。

## 0. 拉代码并确认版本
```
git fetch origin && git checkout main && git pull --ff-only
git rev-parse --short HEAD
git merge-base --is-ancestor 9c917674 HEAD && echo 含本轮热修
```
第三行必须打出「含本轮热修」，否则还没拉到这一版，先别部署。

## 1. 部署
照 `docs/deploy/部署提示词-数据分析真数.md` 全文做，每步回 ✅/❌ + 证据。相比你上次部署，这一版多了三件事：
1. **迁移多了一条**（031 账户昵称归属按业务日生效）：`select count(*) from pgmigrations` 要等于 `ls packages/db/migrations | grep -cE '^[0-9]'`（本版 24，以文件数为准）。
2. **worker 和 data-api 两个进程都配 `DATA_SOURCE_TIMEZONE=Asia/Shanghai`**，不配盯盘没有小时数据。
3. **web 要重新取预编译产物**（`deploy/web-standalone` 分支最新），旧产物里数据总表会整页崩、维度透视会被拦。

至少给**一名真实优化师**建账号、绑他自己的启航 userId、授权他名下账户，跑一次 `worker:once` 抓数，再装快手昵称规则并重解析（部署提示词 5b）。

## 2. 两边数据从哪来（给优化师解释用）
| 空间 | 数据从哪来 | 前提 |
|---|---|---|
| 个人空间 | worker 用**本人启航 userId** 调启航 `get_data`（账户日、离线、实时、小时）→ 存进本库 → 页面读本库 | userId 已绑、账户已授权、`worker:once` 跑过且 `etl_runs` 最新一行成功 |
| 团队空间 | data-api **每次请求实时查 KA Data**（账户日表 + 转化表），不落库；按优化师/目标/承接分组的标签来自本库昵称规则解析 | `KA_DATA_BASE_URL` 与 reader token 已设置（分发方提供）；昵称规则已装 |

## 3. 验收：用优化师账号登录，真浏览器（Chrome / Edge ≥119 / 夸克，**不要 QQ 浏览器**）
每条回：✅/❌、截图、页面上看到的数字；报错的截错误卡（上面有 requestId）。

1. **查昨日本人任务**：大盘选「昨天」，消耗/转化/现金 CPA 是数字不是「−」；和启航后台同范围原始数据对一个数（消耗即可）。
2. **查某任务近七天分版位**：窗口选「近 7 天」，按承接/目标/优化师分组；各组 + 「未标注」加起来 = 大盘合计；点一组能下钻到账户。
3. **修一条归属**：从分析页进账户昵称清洗，改一个账户的归属并保存，刷新回分析页，那个账户换组了。入口找不到就回「无入口」，别手工改库。
4. **切条件同步变**：切日期、优化师、任务，卡片、图、明细、下钻、导出一起变；没数的地方显「−」或缺数提示，不顶上一次的旧数。
5. **缺数照实说**：如果恰好有账户日没拉到数，大盘顶部有缺数横幅、合计标「部分」、达标显「待补齐」而不是判超线。**不要为了模拟去改库或停服务**；没遇到就写「未遇到」。
6. **保存视图与导出**：数据总表存一个列配置视图，离开再回来范围和列还在；点导出能拿到 CSV，用 Excel 打开中文不乱码。

另外顺手看四个 tab：
- **数据总表**：能打开、有账户日行、考核价有数（上一版这里整页崩）。
- **维度透视**：业务×任务、优化师×承接能出表，没归属的格子显「未标注」（上一版这里显「形状对不上」）。
- **团队空间**：切到团队空间，大盘和维度出数；透视只支持**优化师 / 目标 / 承接 / 昵称段**，选任务或业务会提示不支持并列出可用维度——这是预期（团队源没有任务归属）。团队透视本机没有 KA Data 测不了，**你这边是第一次实测**，出错请重点报。
- **盯盘**：名单默认是空的，小时表全是「−」属当前现状。点「加入账户」加一个自己的账户，看小时表出不出数；刷新后名单还在不在，照实报（名单保存可能还没接通）。
