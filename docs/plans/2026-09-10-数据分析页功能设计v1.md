# 数据分析页功能设计 v1（arch 2026-09-10；老板 P0，全员优先）

## 0. 结论
- **现有接口能撑七成**：`POST /data/query` 的 summary（账面 + 现金两组）、trend、dimension（task/biz/account/agent_type/resource_position/bid_tool/is_ubp/deduction_range 八维）、`account.pivot2` 交叉表、盯盘/Gap 树，都在 main 且联调有数。
- **缺三处，由 Codex P-211 补**：① `dimension_type` 加 optimizer / goal / placement + `filters` 多值（optimizer/biz/resource_position/goal）；② summary 加 bi_conv / bi_cash_cost / over_cost；③ `GET /data/filters` 级联选项（只列窗口内 cost>0）。契约 v1.9.22 已定形，**前端不等后端**：按 fixture 先把页做出来，P-211 落地即通。
- **数据源双开门**：团队 = ka-data，个人 = 启航 → ETL → canonical。两条源进同一张事实表，页面不感知来源，只按空间切。

## 1. 页面结构（自上而下）
| 区 | 内容 | 个人视角 | 团队视角 |
|---|---|---|---|
| 顶栏 | **个人｜团队** 切换（= 会话级 switchWorkspace，与左下角同步，切完留本页）、渠道（媒体）选择、日期 chips（今天/昨天/近 7/近 30）+ 月历区间、账户 ID 多值、导出 CSV、保存视图 | 只显本人授权的渠道 | 渠道 + **级联筛选**：优化师 → 业务(大类) → 任务 → 资源位（只列有花费的） |
| KPI 第一行（账面） | 花费 / 激励 / 转化 / 转化成本 + 环比 | 同 | 同 |
| KPI 第二行（考核） | 现金花费 / 考核 BI 数（下标回传 GAP）/ BI 现金成本 / 超成本金额（正红负绿）+ 环比 | 同 | 同 |
| 趋势 | 双轴折线：消耗 / 转化（右轴）/ 转化成本（虚线）；日粒度，小时等 025 | 同 | 同 |
| 任务大类表现 | 业务(biz) 行 → 展开细分任务(task)；11 列（消耗/激励/转化/转化成本/考核BI/回传GAP/考核价/BI现金成本/超成本/消耗占比） | 只本人任务 | 全量 |
| 优化师概览 | **三级钻取**：优化师 → 业务 → 任务 → 账户，BI 按消耗占比分摊到下级 | 折成「我的任务 → 账户」两级 | 全量 |
| 分布组件（可换图型） | 资源位分布、版位分布、转化目标分布（个人重点看版位/成本）、自投/代理 | 同 | 同 |
| 交叉表 | 已有 `pivot2`（八维两两）| 同 | 同 |
| 盯盘 / Gap 树 | 已有，保留为 tab | 同 | 同 |

## 3. 图表类型切换
每个分布/趋势组件右上角「图型」：分布组件 ∈ {环、饼、柱}；趋势 ∈ {折线、柱}；任务/优化师表固定表格。偏好写 `saved_views.config.charts[widgetKey]`，未保存用默认。库 fe 自选（ECharts 可，自托管）。

## 4. 空态与口径（沿用契约）
