## 已完成

1. 输出 Schema 升级为 v2，新增 `alignmentStatus` 和无时间 `semanticSections`。
2. `whole_video` 允许多个有序语义段，但强制 `segments=[]`；任何虚假逐句秒点都 fail-closed。
3. `segment` 字幕继续要求精确叙事时间段无缝覆盖全片；时间段引用的字幕/镜头证据必须与本段真实相交。
4. 每个语义段必须至少引用一条文稿证据；整段 ASR 的语义段只能引用全文证据，不能借 shot ID 暗示已完成对齐。
5. Prompt 升级 `teardown-v3`，固定源/模板 SHA，按七模块目标引导全局定位、故事爆点、受众、文稿结构、时间证据、复刻和 CTA。
6. 既有逐镜头中点帧、Hook 15 格和全片 36 格保留；新增每页最多 36 个、6 列的逐镜头帧墙，多页按镜头索引连续覆盖。
7. placeholder 用 FFmpeg 本地灰块占位，不移动镜头编号；单页失败只标记 unavailable，不拖垮整条拆片。
8. 帧墙最多两页并发生成，避免 500 镜素材同时启动约 14 路 FFmpeg。
9. Handler 内部 completed 结果直接返回 `film + transcript + analysis`，未来页面不用从 Agent 文本反解析帧墙或文稿。
10. B14 旧 analysis 缓存缺 v2 字段时只重跑 Agent；旧 film 缓存没有逐镜头帧墙清单时重跑 FFmpeg，ASR 和可复用分析不重复执行。
