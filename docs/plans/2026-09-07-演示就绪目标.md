# 演示就绪（Demo-Ready）目标定义（老板 2026-09-07：给技术同学看的要像成品，不要半成品）

> 这是 arch 循环工程的**靶子**。每一圈都问一句：离下面这条路径还差什么？差什么就先做什么。

## 一、判据：一条完整可演示路径能走通

登录 → 工作台看今日队列 → 账户池看九态与达标色标 → 数据分析看大盘/趋势/维度 → 任务详情看八页签 → 变更集试运行（不真写）→ 报告看日报

**每一步都必须**：真接口（不是 fixture）、真数据库、缺数显 −（不补 0）、颜色从后端 DTO 来（前端不自己算）、切团队空间能看到只读态。

## 三、加分项（P1，有时间就做）

- 归属清洗页（昵称解析）——这是差异化亮点，技术同学会问"你们怎么做归属的"
- 知识库（复制 ContentRadar 编辑器，已铺前端）
- Agent 抽屉 + ⌘K
- 团队空间真数据（R-011 团队快照）

## 四、明确不做（演示时直接说明）

- 真实媒体写（全程只到试运行，写开关关死）
- 素材拆片（依赖 FFmpeg + ASR，未部署）
- BUC 正式登录（内测用账密）
- 移动端

## 五、给技术同学看的时候怎么说

一句话：「**内网数据拉进自有库 → 算达标和差距 → 给建议和一键操作 → 人确认后才写回媒体**。现在数据链路和建议链路都通了，写回media 那一段全关着，正好想请教怎么正规化。」

演示顺序按 §一 那条路径走，边走边说三件我们做对的事：缺数不补 0、所有归属都能人工改、写操作必须人确认。
