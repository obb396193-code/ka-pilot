## 1. 通用准入规则

1. 联调只在 daily/隔离测试环境开始；每个探针必须有执行人、时间、代码 SHA、配置版本、trace/run/job ID 和脱敏结果。
2. 真实凭证只由授权人写入 Secret 服务或平台配置，不进仓库、Issue、聊天、截图、命令历史、请求正文、业务数据库或应用日志。
3. fake upstream、mock HTTP、内存端口和本地 PostgreSQL 只能证明代码链路，证据标题必须带 `fake/mock/local`。
4. 所有媒体写操作必须先生成 preview/changeset，再由有权限的人确认；UNKNOWN 只读对账，禁止盲重试。
5. 不知道的接口、字段、网络策略和错误码标“待平台确认”，不能从 CLI 行为反推出公开协议。
6. 任一通路出现跨 workspace、换凭证重试、明文凭证、无审计写入或 fake/real 混标，立即停止联调并按 P0 处理。

## 3. 分阶段放行

### Gate A：本地代码（当前可做）

- 默认测试、typecheck、lint、coverage、dependency audit、迁移回放通过；
- fake/local 证据带明确标签；
- 资源预算、租户隔离、凭证扫描和写确认反例通过。

### Gate B：daily 只读

- Secret 服务正式调用方式和奇航/Multica 正式入口由 owner 书面或可复核样本确认；
- 奇航四资源、模型五能力、Multica/OS read、PG/FaaS 连接均产生真实 trace；
- 未知账户不自动写入任意 workspace；数据字段漂移先隔离。

### Gate C：daily preview

- OS/CLI preview 返回可稳定映射到 changeset、from-value、hash、TTL 和逐项目标；
- preview 重复调用无媒体副作用；
- 目标对象到 workspace/account 的权威权限矩阵已冻结。

### Gate D：受控 execute

- Claude/arch 复核 B3/B7 与 P0-07/P0-13；
- 老板对具体测试动作另行确认；
- UNKNOWN 只读 reconcile、幂等、逐项部分成功和反向 changeset 已在 daily 实测；
- 钉钉卡片如作为确认入口，先补 P0-12 durable inbox/ACK/outbox。

### Gate E：生产

- BUC/RBAC、应用身份、Secret 服务、网络白名单、安全 CR、监控告警、备份恢复、24h 稳定性全部有 owner 签字；
- 二期部门推广不得继续依赖某一个人的个人权限；
- 生产 SLA 必须来自真实 FaaS/PG/上游压测，不使用 `B8a-数据链性能基线.md` 的纯内存数字。

## 5. 联调证据模板

每个真实探针单独建 `docs/evidence/integration/<date>-<channel>-<probe>.md`，只写：

```text
环境 / 应用版本 / 代码 SHA / 配置版本（无 secret）
执行人 / 授权范围 / 开始结束时间
输入规模与脱敏对象类型
产品 trace/job/run ID
外部 run/reference ID（若平台提供）
成功/失败分类、重试次数、耗时、行数/字节数
写操作的 preview hash、确认人、最终态、回滚结果
日志和截图位置（已脱敏）
仍未证实事项
```

没有以上证据的通路，状态只能是“未联调”。
