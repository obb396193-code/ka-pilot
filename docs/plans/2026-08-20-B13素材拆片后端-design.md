> 日期：2026-08-20

## 1. 目标与非目标

### 目标

在 B12 已有安全视频来源候选之后，建立一条可测试、可恢复、可替换 Provider 的素材拆片后端内核：

1. 安全下载候选视频并形成内容哈希和本地受控临时文件；
2. 复用 ContentRadar 的 FFmpeg 抽帧、镜头时间轴和“失败帧占位不移位”方法；
3. 平台字幕优先，没有字幕时只允许 API Key 云 ASR；
4. 生成带来源证据的结构化拆片结果：钩子、卖点、人群、节奏、CTA、片段、镜头和复刻建议；
5. 通过现有 Claude Agent SDK + localhost 多模型网关执行结构化分析，不限定单一模型；
6. 每一阶段有稳定输入指纹、错误码和可回放产物，避免重试重复下载、重复 ASR 和重复模型调用。

### 本批不做

- 不实现商品池和承接页资产，等待 OS 第五轮；
- 不创建公开 API、数据库 migration 或正式 `job_type`；
- 不修改生产 Runtime，不声称已部署或在线；
- 不做本地 ASR，不引入 Whisper/faster-whisper；
- 不把每个片段物理导出成 MP4；一期先做结构拆片和证据帧；
- 不做相似向量检索、素材复刻下单和前端页面，它们消费 B13 结果但不属于本批。

## 3. 方案对比

### A. Worker 确定性管线（采用）

下载、FFmpeg、字幕选择和阶段 checkpoint 由代码控制；Agent 只分析已形成的证据包。

优点：结果可复现、失败可定位、成本可控、可跨模型；OS 只负责受权来源获取。

### B. 整体交给 OS Agent

优点是开发快；缺点是异步对话、自由文本、失败恢复和批量成本不可控，无法成为产品级媒体流水线。

### C. 整段视频直接喂多模态模型

优点是链路短；缺点是长视频限制、时间戳和镜头对齐不稳定、成本较高。未来可作为增强，不作默认主链。

## 4. 分层架构

```text
OS Source Bridge / 用户上传
  → MaterialSourceCandidate
  → 安全下载与内容哈希
  → 受控临时媒体文件
      ├─ 平台字幕验证 ───────────────┐
      ├─ 无字幕 → CloudAsrPort ─────┤
      └─ FFprobe/FFmpeg 视觉工位 ───┤
                                     ↓
                       TeardownEvidencePackage
                                     ↓
                   Claude Agent SDK + 多模型网关
                                     ↓
                         MaterialTeardownResult
```

### 4.1 媒体下载工位

`MaterialDownloadService` 不信任 B12 探针结果可以永久复用。真正下载时重新执行 URL/host/redirect/content-type/size 门禁，流式读取时再次执行字节上限。

OS 第四轮真实 CDN 响应的 `Content-Type` 为 `application/octet-stream`，而 B12 当前只接受 `video/*`。B13 必须收紧地修正这一兼容点：只有来源 host 已在部署 allowlist、素材元数据声明为 VIDEO 且长度受控时，才允许 `application/octet-stream` 进入下载；下载后必须由 FFprobe 确认存在合法视频流。其他未知二进制仍拒绝，不能把“兼容快手 CDN”扩成任意文件下载。

输出只包含：内容 SHA-256、字节数、媒体类型、临时文件句柄和来源证据指纹。日志、错误和观测不得包含完整签名 URL。

临时文件使用任务专属目录；成功后由后续工位读取，失败或结束后 `finally` 清理。下载一半、长度漂移、重定向越界、超限、内容类型漂移全部 fail-closed。

### 4.2 字幕/文案工位

统一结构：

```ts
interface TranscriptSegment {
  startMs: number;
  endMs: number;
  text: string;
  source: "platform_caption" | "cloud_asr";
}
```

选择顺序：

1. 平台字幕存在且 Schema、时间轴、总时长边界通过校验 → 直接使用；
2. 否则调用 `CloudAsrPort`；
3. 云 Provider 未配置或失败 → 返回 `blocked_transcript_provider`/稳定失败，不偷偷落到本地 ASR。

API Key 只通过现有凭证 Resolver/Secret reference 获取，不能出现在 job payload、Prompt、事件或错误中。云 ASR 的最终厂商适配器等接口实证后单独实现；B13a 先冻结端口、输入输出和降级行为。

### 4.3 FFmpeg 视觉工位

复用 ContentRadar 已验证方法而不复制其运行状态：

- FFprobe 获取总时长、视频流、尺寸和基础格式；
- scene threshold `0.15` 形成视觉事件，`0.30` 形成硬切候选；
- 计算硬切数、视觉事件数、ASL、前 3/30 秒视觉密度；
- 为 Shot 选择中点代表帧；失败帧生成占位记录，不删除数组元素，保证 Shot 与 frame index 一一对应；
- 生成 Hook contact sheet、全片 contact sheet 和受预算限制的逐镜头 sheet 计划。

所有命令使用参数数组调用固定 `ffmpeg/ffprobe`，禁止 shell 字符串；路径必须位于任务临时根目录；限制时长、输出帧数、进程超时和 stderr 大小。

### 4.4 证据包与模型工位

`TeardownEvidencePackage` 只含：

- 媒体身份、总时长和内容哈希；
- 连续的字幕/ASR 时间轴；
- Shot 起止、代表帧引用、视觉事件与汇总指标；
- 明确的证据 ID，不含业务凭证、签名 URL和后台未提供指标。

版本化 Prompt 以本地优质 Prompt 为基线：

- `/Users/aik/Documents/Obsidian Vault/raw/学习/提示词/拆片提示词.md`
- `/Users/aik/Documents/Obsidian Vault/knowledge/概念/拆片提示词设计.md`

实施时复制快照进 KA 自己的 Prompt Registry，记录版本和 SHA；运行时不依赖个人 Obsidian 路径。

模型只能输出 JSON Schema 允许的字段。至少包含：片段时间轴、Hook、卖点、人群、节奏、CTA、证据引用、复刻建议和不确定项。严禁生成或推断完播率、GMV、转化率等输入证据不存在的后台指标。

模型调用通过 B5 Provider Router 与 credential envelope 选择 Claude 或兼容模型；结构拆片使用 `background + structuredOutput` 能力，不开启 Bash/Read/Write/Web/任意 Skill。

## 5. 幂等与阶段状态

阶段键由以下稳定值生成：

- download：来源证据指纹 + 来源素材版本；
- transcript：媒体内容 SHA + 字幕版本或云 ASR Provider/模型版本；
- visual：媒体内容 SHA + FFmpeg 分析配置版本；
- analysis：transcript fingerprint + visual fingerprint + Prompt version + Schema version + Provider/模型版本。

媒体内容 SHA 相同才允许复用下载后的衍生产物。来源 URL 相同不能作为复用依据，因为签名 URL 会变化。

B13a 内核返回阶段状态和稳定失败码；正式 checkpoint 表、任务恢复和产物表等待 arch/Claude 冻结契约后再接数据库。

## 6. 错误与降级

| 场景 | 行为 |
|---|---|
| 签名 URL 失效 | 标记 `source_expired`，回 Source Bridge 刷新，不用旧 URL 无限重试 |
| 平台字幕无效 | 记录安全原因，转云 ASR |
| 云 ASR 未配置 | `blocked_transcript_provider`，不落本地 ASR |
| 个别帧提取失败 | 保留占位 frame evidence，继续；超过失败比例则视觉工位失败 |
| FFmpeg/FFprobe 超时 | 终止子进程，清理临时目录，稳定错误码 |
| 模型 JSON 不合法 | Schema 失败，可按预算换 Provider；不得把自由文本当成功结果 |
| 任一阶段凭证形状文本 | 拒绝进入事件和持久化产物 |

## 7. 测试策略

### Domain

- 字幕时间轴边界、重叠、空文本、总时长越界；
- 证据 ID 稳定性和引用完整性；
- 输出 Schema、无证据指标、幂等 fingerprint；
- 平台字幕优先与云 ASR 兜底，不存在本地 ASR 分支。

### Worker

- 下载逐跳校验、Range/长度漂移、流式超限、清理和 URL 脱敏；
- `application/octet-stream` 只有在 allowlist + VIDEO 元数据 + FFprobe 三重门满足时通过；
- FFprobe/FFmpeg 参数数组、超时、stderr 上限、切点解析、占位帧对齐；
- Prompt/Schema 版本快照；
- Agent SDK structured output 成功、非法 JSON、Provider fallback 和凭证不泄漏。

### 集成门禁

- 使用生成的短小假视频跑真实 FFmpeg smoke，不使用公司素材；
- 云 ASR 使用 fake adapter，真实 Provider 必须在接口与权限确认后 opt-in；
- 不把 OS 沙箱回传冒充 FaaS/生产联调。
