# 双维透视聚合 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** account.pivot2 strict v1 rows 与逐账户日双维聚合，后续接 DB/Registry/HTTP，不平均 CPA 或将单维表拼接。
