## 目标

- 支持每期字段变化，但新模板不覆盖旧结算单。
- 月中试算和正式出单共用同一套确定性字段映射/公式/校验。
- 实际返点与估算返点按模板显式对账，不硬编码系数或容差。
- 人工修正可追溯，冻结后的值快照可独立复核。

## 已完成

1. 新增 v1 `SettlementTemplate`：1~50 字段、0~50 检查、显式 order、类型、来源、required、allowCorrection、aggregation 和 fingerprint。
2. 字段来源只允许事实键或受限四则表达式树；无 Excel/JS/SQL 字符串执行，表达式深度/节点/引用/循环均有界验证。
3. numeric 字段可显式 `aggregation=sum`；text/date 禁止求和，任一行缺值时总计为 null，聚合数值越界失败。
4. 预览只接受 `offline_settlement` 口径；结算期、数据截止、生成时间均规范且截止不得早于期末。
5. 最多 1000 行、每行最多 200 个事实；事实 ID 完全重试幂等、冲突失败，rowKey 唯一，输入顺序不影响结果。
6. 字段缺失/类型错误/公式无定义与对账 mismatch/undefined 均产出稳定 issue；block/warn 与容差完全由模板声明，无隐藏默认值。
7. 修正事件按时间+ID 稳定执行，绑定行/字段/from/to/理由/操作者/证据；仅 allowCorrection 字段可改，from-value 不一致失败。
8. 预览完整性校验覆盖模板快照、row fingerprint、字段/检查形状、重算检查、重算总计、修正 fingerprint 与时间链；重算外层 hash 不能绕过。
9. 只有无 blocking issue 的预览可冻结；冻结单内嵌模板快照、值/总计/检查、事实/修正 fingerprint 和确认人/时间，新模板不会改变旧单。
