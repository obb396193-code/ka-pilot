# P198 出站投递 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 消费真实 outbound_messages，按 arch v1.9.42/46 发送钉钉消息，正确持久化重试与未知结果；不是新增一个仅供演示的队列。

**Architecture:** 单轮、限定 workspace、复用 workerOnceLock；领取与结果更新短事务并带 fencing token，HTTP 不占数据库事务。Domain 决定去重和尝试结果，DB 持久化 due/claim/unknown 状态，Worker 调用经过服务端接收人解析的 Transport。

**Tech Stack:** TypeScript、Zod、PostgreSQL、Node crypto/fetch、Vitest；不增加依赖。
