## 目标

- 按老板裁决先做低复杂度诊断：一条视频只调用一次 IdeaLab 风格 ASR，拿整段文本，不做切块和句级时间戳。
- 无时间戳时诚实降级，禁止 Agent 把全文中的句子编到具体秒点或镜头。
- 素材签名 URL 每次执行重新获取并立即下载，不把会重签、会过期的 URL 当长期任务输入。

## 已完成

1. 字幕时间精度显式区分 `segment` 与 `whole_video`，进入字幕、证据和分析 fingerprint。
2. 严格 `{kind:"whole_text",text}` 云结果只生成一个 `0..durationMs` 全片字幕段；既有时间轴字幕保持 `segment`。
3. `whole_video` 证据只允许一个覆盖全片的 `other` 分析段；逐秒、多段或非 `other` 结果均拒绝。
4. 拆片 Prompt 升级 `teardown-v2`，明示钩子只能作为全文候选、位置不确定，并固定模板 SHA 防漂移。
5. 新增 `WholeTextCloudAsrAdapter`：每条视频调用一次可注入 transport，绑定 provider/model/profile，只接收严格 `{text}`。
6. ASR adapter 在调用 transport 前校验媒体 SHA、受控 handle 与时长；Provider 异常和非法响应只返回稳定错误，不回显路径、凭证或正文。
7. Handler 输入改为稳定 opaque `sourceRef`，每次运行先 `MaterialUrlLeasePort.acquire` 再立即下载；重试仍重新领取 URL。
8. 即使 URL 重签但内容 SHA 相同，FFmpeg、字幕和分析 checkpoint 仍可复用；checkpoint 不保存 candidate 或签名 URL。

## 当前边界

- `WholeTextAsrTransport` 是已测试的内部适配边界，不是已经联网的 IdeaLab 客户端；真实 endpoint、AK secret reference、multipart 字段、文件限制、超时和计费尚待 OS/平台正式契约。
- `MaterialUrlLeasePort` 只冻结“稳定引用换临时 URL”的调用顺序；OS/Multica 的 sourceRef 格式与调用协议未猜测、未实现。
- 当前整段结果没有句级时间戳，只能做全文文案、钩子候选、卖点、CTA 和整体结构诊断，不能精确定位台词到秒或镜头。
- 真实投放帧外发仍维持 B13 阻断；本批没有解除多模态 Provider 的数据边界。
- 未注册正式 Job/API/DB/Runtime，也未修改公开 Contract、migration 或前端。
