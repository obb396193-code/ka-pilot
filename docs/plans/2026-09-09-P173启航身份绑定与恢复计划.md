# P173 启航身份绑定与恢复 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** F-OS-002提供部署CLI绑定当前个人空间用户的启航身份，并安全恢复因身份未补齐而阻塞的同owner job。

**Architecture:** strict CLI输入workspace_id+(user_id或identity_id)+qihang_user_id；数据库事务锁定唯一active personal身份链，仅改users.qihang_user_id。绑定命令不改session/role/grant/job。恢复另在可信tick新鲜批准上下文下进行，原owner/workspace/media/date不可变，缺grant仍拒绝，不删job。

**Tech Stack:** Domain zod、pg、tsx CLI、Vitest、真实PG。

---

## Task 1：绑定CLI（先独立交付）

- New Domain `src/qihang-identity-seed.ts` 与 `test/qihang-identity-seed.test.ts`：strict互斥选择器、非空有界qid、结果禁止qid。
- New DB `src/qihang-identity-seed-repository.ts`、`src/seed-qihang-identity.ts`；追加本人index导出、package.json命令。
- New DB unit/PG测试：同值no-op、异值无force拒绝/force替换，跨workspace/missing/inactive/ambiguous/team拒绝；并发不发生隐式覆盖；输出与错误不泄qid；只改目标用户一列。
- 先红→实现→定向PG/type/lint/audit；CLI真实子进程合成库验证。

## Task 2：恢复（不能把Task1标成完整F-OS-002）

- 审计blocked的两条来源：tick初建的QIHANG_IDENTITY_MISSING，以及执行时 Credential owner has no usable Qihang identity。
- 只在active唯一身份+媒体tuple grants重新验证之后恢复；必须匹配原job的workspace、credential owner、media/businessDate/类型；不能因换了老板凭证而恢复。
- 原始blocked原因、attempt与执行历史保留；不能借通用enqueue放开所有blocked/failed终态。
- 真PG：命令补齐→实际tick恢复→实际once读取；无grant/撤权/变owner/跨空间仍拒绝，并发只一次有效恢复。
- 更新唯一部署runbook的本人命令说明，交审独立SHA，不push/真实媒体写。

### Task2逐文件细化（开始实现前）

- Domain `workspace-sync-scheduler.ts` 提取 approved payload 构造函数，由原Service与恢复共同使用，避免两套shape漂移；业务日期保持原job日期。
- DB新 `qihang-job-recovery.ts`：current snapshot strict校验，短事务锁active personal身份链及原tuple授权；只选同workspace/owner/media的身份缺失blocked任务，1001哨兵拒绝过量。初始无scope blocked可首次补齐；已有approved snapshot只能保留原scope，不扩户。写job状态与audit同事务，保留attempts/last_error与历史ETL。非身份原因/耗尽/运行中/终态不恢复。
- DB `job-repository.ts` 只加明确恢复方法，不放宽普通幂等；Worker `scheduling/workspace-sync-service.ts` 在approved candidate入队前调用，覆盖历史日期的同owner阻塞。
- 新DB真实PG：无qid、无grant、撤权、inactive、team、跨媒体同号/跨workspace、不同owner、并发一次audit、旧日期、attempt保留、非身份原因；新Worker PG：原once blocked→正式CLI绑定→原once成功，无私密凭证落payload/audit。
- 先Worker端到端真实红→Domain/helper→DB事务→Service接线→定向PG、type/lint/audit；磁盘满足8GiB才全量。
