## 目标

- 把 B15 的钩子、结构、卖点、人群、节奏、CTA 转成稳定、可索引的内容画像。
- 给优化师未来的“相似素材”页面提供可解释分项，而不是只给一个模型黑盒分数。
- 证据不足时拒绝输出伪精确总分。
- 把“内容相似”与“复刻自”分开：前者是算法结果，后者是明确业务事实。

## 已完成

1. 新增 `MaterialSimilarityProfile` v1，绑定素材版本、B15 拆片 fingerprint、语义角色序列、钩子类型、四组文本 token 与视觉节奏值。
2. 中文使用字符二元组、拉丁/数字使用词项+三元组；所有 token 去重排序并限制 512 个，源数组顺序不影响画像 fingerprint。
3. 六组件评分：结构 20%、钩子 15%、卖点 25%、人群 10%、节奏 20%、CTA 10%。
4. 每个组件返回 `compared/unavailable`、分数、原始权重和解释码；缺项从分母移除并显式列出。
5. 少于 3 个可比组件或可比原始权重小于 0.50 时返回 `insufficient_evidence + score=null`。
6. 比较结果对左右输入顺序对称，带稳定 fingerprint；画像版本漂移和 fingerprint 篡改 fail-closed。
7. 新增独立复刻谱系对象 v1：源/派生素材版本、复刻方式、源拆片 fingerprint、创建人/时间、可选备注和稳定 fingerprint。
8. 谱系拒绝自环、非法标识、非法 SHA、非规范时间、未来时间、超长备注和未知字段；结果深冻结。

## 当前边界

- 这是确定性内容结构相似度，不代表素材质量、跑量概率、转化效果或推荐顺序。
- 没有 Embedding、向量库或模型重排；同义改写召回能力有限。
- 没有自动认定复刻关系；谱系只能由明确用户动作或可审计流程创建。
- 未修改 `packages/contract/**`、`packages/db/migrations/**`、`apps/worker/src/runtime.ts` 或 `apps/web/**`。
- 验收基线 6.3/6.6 仍不能标“产品已完成”：列表检索、持久化、API 和页面均未接。
