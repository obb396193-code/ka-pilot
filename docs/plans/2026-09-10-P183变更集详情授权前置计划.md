# P183 变更集详情授权前置 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** P-178 中 changeset HTTP 详情在读取正文/items前应用共享授权谓词，保留404/403及后台job边界。

**Architecture:** Service必须把唯一ApprovedWorkspaceAuthContext传给仓储。三参find用于会话读取，内部两参find保留给已锁父记录的执行/回收链。会话读取在同一RR/RO事务先仅SELECT id/workspace/allowed，不读正文；授权通过后再按相同谓词读取header/items。

**Tech Stack:** TypeScript、PostgreSQL、Vitest、现有accountScopeParams/accountScopeClause与SemanticReadSnapshot。
