# 账户静音存储 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 按已冻结 account_mutes 三键建立个人授权账户静音存取内核，不再写工作项旧日期列。

**Architecture:** 服务端传 ApprovedWorkspaceAuthContext 和明确 mutedUntil 日期；DB 在同事务复核 active identity/member/user、personal workspace 与真实 grant 后锁定目标账户再 UPSERT。读取同样限当前授权三键。日期如何从 days 计算、触发抑制和公开响应仍由 arch 冻结，不在此猜测。

**Tech Stack:** TypeScript、现有 Domain Zod auth schema、pg、Vitest；不加依赖/迁移。

执行技能在本环境不可用；用户已授权连续实施，由主 Agent 按 TDD 执行，不额外开子 Agent。
