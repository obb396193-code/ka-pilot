# 发给内网 OS：启航第三轮最小只读探针

只做只读 GET，不测试任何媒体写操作，不做压力测试。真实 userId、账户 ID、广告 ID、名称、金额和完整响应不要回传；只回传脱敏命令模板、状态、行数关系、字段/错误结构和结论。

## 1. realtime 历史日期

选择本人已授权且已知昨日有投放的一个账户，分别请求：

```text
resource=account_realtime, ds=今日
resource=account_realtime, ds=昨日
resource=ad_realtime, ds=昨日, accountIds=<本人授权账户>
```

需要回答：历史 ds 是成功有数据、成功空数组还是业务/HTTP 错误；返回 ds/last_sync_time 如何表达。不要把 Skill 源码意图当执行结果。

## 2. hh 边界

在同一授权账户、同一数据日分别请求 `hh=0/23/24/25`；若当天未到目标小时，只验证参数是否被接受可能不可靠，可选择已有完整历史日，但须先确认历史 realtime 可用。

需要回答：各值的 HTTP/业务状态、是否返回、错误 code/message 结构；不回传业务明细。

## 3. 疑似固定行数截断

- 对已知会命中固定整数边界的安全范围，只读检查顶层 envelope 是否存在 total、hasMore、nextPage、truncated、limit 等隐藏字段。
- 用相同范围按 accountIds 小批拆分，比较“分片去重并集行数”是否大于无过滤结果。
- 如果单账户仍命中边界，并且已有合法广告 ID 列表，再用 adIds 小批拆分对比；不要为了造大样本扩大权限或压测。

需要回答：固定边界是否被分片并集突破、是否存在重复、是否有截断提示。不能证明时继续标“疑似”。

## 4. 分页参数探针

只在上述同一安全范围，给数组接口附加 `pageNum=1&pageSize=小值`，观察参数被接受、忽略还是报错；不要循环翻页。

## 回传格式

每项按：真实执行/文档确认/源码意图/推断 四级标记，并列明与第二轮结论是否冲突。凭证和业务数据不回传。
