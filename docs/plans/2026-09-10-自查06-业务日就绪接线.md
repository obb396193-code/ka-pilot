# 业务日就绪接线 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 按 arch v1.9.24，将历史 full 成功标记替换为请求窗口内授权 tuple-day 的 canonical 可读状态。

**Architecture:** 共享 readiness SQL 复用 etlBatchReadableSql，空 scope、缺 canonical/computed_at、失败未重算均 false。页面只传 businessDate；调度使用即将排队的固定窗口，恢复使用每个原 job 的冻结日期和授权快照。批量读取避免 N+1，不改公开响应字段、不启用 Runtime 容错。

**Tech Stack:** TypeScript、Vitest、PostgreSQL 参数化 SQL / RR 只读事务。
