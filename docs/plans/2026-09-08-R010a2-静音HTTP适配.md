# R010a2 静音 HTTP 适配 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> 子技能不可用，按已有冻结需求本地TDD执行。

**Goal:** 给arch可接入的R010独立路由：户级静音和ignore+mute，复用P131原子服务，不占R014注册数组。
**Architecture:** 导出结构兼容壳层的route factory，context只收服务器已批准auth；路由仍验证personal、严格路径/body/result，提供requestId/有界JSON/固定错误。没有另造登录、监听端口或全局路由注册；正式上线由arch接共享composition。
**Tech Stack:** Node HTTP、TypeScript、Zod、Vitest。

### 2. 实现

- 新 `apps/worker/src/r010/{routes,http,account-mute-routes}.ts`：仅自己目录，无全局副作用。公共上下文同已有shell，不依赖be2内部函数。
- `AccountMuteService`仍唯一写业务规则/鉴权/事务入口；HTTP不连库、不发Job、不碰媒体。异常只映射固定status/code/message，不透传下游body。
- envelope沿用`{ok:true,data,meta:{requestId}}`；只允许POST，任意scope/dataSource等多余字段拒绝。通过service成功值schema后才发送。
