# R010a2 D6 变更集试运行服务 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 把已有 prepareDryRun/recordDryRun 接成仅个人授权账户可调用的服务；没有真实预检 Provider 时明确不可用，停在 confirm 前。

**Architecture:** 复用 ChangeSetRepository 的短事务/精确 TTL 指纹/原子记录，不接 ChangeExecutor、JobRepository 或媒体写。服务入口只收服务端 ApprovedWorkspaceAuthContext 和 changeset id；独立只读 PreflightPort 返回全量 item 结果，校验范围、指纹、数量、类型后才记录。HTTP 注册属于 arch，先交可测试服务端口，不占 be2 r014 块。

**Tech Stack:** TypeScript / Zod / Vitest / PostgreSQL；不新增依赖。

## Task 1：失败测试与服务端口

- 新建 `apps/worker/test/changeset-dry-run-service.test.ts`，先运行 `npx vitest run test/changeset-dry-run-service.test.ts` 证明缺实现。
- 新建 `apps/worker/src/changesets/dry-run-service.ts` 和 `dry-run-contract.ts`（内部端口，不是公开 DTO）。
- 覆盖 team/无权/read-only/同号跨媒体/跨 workspace/id/其他 credential owner；在 Provider 前拒绝。
- trusted Provider 返回范围、draftHash 与逐项结果，数量≤10000、传输严格小于16MiB；不接受秘密/任意上游错误作为 failReason。保留 unknown，不转 success。
- prepare 后再核范围；请求和返回深克隆，Provider 不得修改私有授权或待记录草稿。
- 修改 `packages/db/src/changeset-repository.ts`：recordDryRun 可接服务端 expectedScope，在保存记录的同一行锁内核对 media/account/initiator/credential owner；避免不含身份的 value/TTL hash 被重分配凭证的草稿复用。
- 本地 clock/timeout 参数受限；超时取消信号且不继续 record；原始错误只映射稳定内部错误。
