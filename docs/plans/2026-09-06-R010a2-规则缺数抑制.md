# 规则缺数抑制 Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将metrics.md §12.8已冻结的缺数/源过期/首次full门接入现有RuleScanHandler，缺证据不得创建/合并/推送告警。

**Architecture:** Domain纯函数解析受信规则provider的必需指标与来源证据，输出checked/undeterminable/pending；Worker先执行门再算阈值。coverage按账户三键去重，跨规则最保守状态优先。缺数不传给工作项sink，因而不递增或消触；不伪造SLA暂停持久化已完成。

**Tech Stack:** TypeScript、现有Zod/Vitest、RuleCandidateProvider/RuleScanHandler内部端口。无公开DTO/迁移/媒体调用。

## Task 1：Domain门
