# 前端原型图生成指令（Codex R-002 用）

> 2026-08-18 arch 出稿。用法：每页一次生成，**通用前缀 + 该页提示词** 拼接后喂图像模型。横版 16:9（建议 1920×1080 或 1440×900）。
> 目的：给老板拍板视觉方向，不是像素稿。生成后按 R-002 自查项检查，中文乱码/布局跑偏必须重生成。

## 通用前缀（每页都带）

```
高保真 Web 应用 UI 设计图，中文界面，企业级数据产品，Apple 风格极简设计。
设计系统严格遵循：
- 背景：页面底色 #f5f5f7，内容卡片纯白 #ffffff，1px #e8e8ed 边框，12px 圆角，阴影极轻
- 主色：橙色 #ff6a2c 仅用于强调按钮/选中态/关键数字，用量克制
- 文字：深灰 #1d1d1f 主文字，#86868b 次要文字，无衬线字体，中文清晰可读
- 语义色：红 #e5484d 仅表示超标/负向，绿 #00875f 仅表示达标/正向，禁止彩虹色
- 数字：等宽数字风格，表格中右对齐，金额带 ¥ 和千分位
- 状态标签：胶囊形 chip（达标=绿底白字、超考核=红底白字、观察=灰、冷启动=蓝）
- 顶部导航栏 56px 白底：左侧 Logo「投放工作台」+ 9 个导航项（工作台、投放任务、数据分析、账户资源、自动化、商品素材、报告、知识库、钉钉中心），右侧搜索图标+用户头像（导航已老板定稿，图中按此为准）
- 无左侧边栏，内容区居中最大 1440px
- 整体气质：数据密集但呼吸感强，专业、克制、高级，类似 Linear/Stripe Dashboard 的品质感
画面为完整浏览器视口内的单个页面，不要手机壳，不要多页拼贴。
```

## 自查清单（每页生成后过一遍）

1. 中文全部清晰无乱码伪字
2. 主橙只出现在强调处（选中态/主按钮/关键警示），没有大面积橙
3. 红绿只用于超标/达标语义
4. 数字等宽感、表格右对齐
5. 布局与本页 ASCII/描述一致（栏数/卡片数/按钮位置）
6. 导航栏 7 项齐且当前页选中态正确
7. 整体像 Linear/Stripe 品质而非 AntD 默认风
