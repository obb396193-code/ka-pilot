### 路2：第一性原理审查 ✅（2026-08-17）

总判断：真实产品是「队列+透视+Gap+写链路+日报」五件套，其余多为待重设计对象。

**优先级纠错（arch 认可，四条全采）**：

4. 优质户复制+垃圾清理应第一批上（对应"处理账户2-3小时"最大时间块）

**空置风险清单（按老板方向消化为"改到有人用"而非砍）**：
- 策略中心：打法是个人竞争力无人愿录 → 改为任务详情"打法备注"自由文本起步，自动沉淀

- 素材复刻谱系 → 降为下单表单"复刻自"字段 + group by
- Shadow Mode：产品定位人拍板，无无人值守对象 → 保留概念，实现推迟到真开自动化时
- 工作流设计器：低代码教训=业务用户不编排 → 用户面砍，工程内规保留（幂等/UNKNOWN对账/冲突锁）

**顾虑**：处理条数/响应时长**绝不能进任何可导出报表**（发现能截图考核→刷指标→数据当天失真）；审批流配**默认授权规则**（同类批3次后可设免审门槛——审批流的减法机制）+批量批+超时转授权；自动化夜间分级限额（单日累计影响金额上限，超限降级为建议）；导航按角色不按功能域；**别和技术部门打数据仗**（出口径差异说明页）。

**推广四门槛**：30天实证三个数（日均省X分钟/响应时长降幅/漏看归零）；数字先跟Excel对平（口径不平第一次打开就永远不开）；第二渠道接入≤4周可承诺；**合规通道先谈妥是前置条件不是待办**（1人用是效率工具30人用是数据安全事故）。

**更高层五缺**：核心目标进度要三元组（目标X→当前Y→按趋势预计Z）；钱的绝对量级必须在；异常三条格式=事+影响金额+**已做了什么**+需不需要我（多数答案应是"已处理不需要你"）；拍板项要能拍（钉钉三键：同意/驳回/找我聊——更高层屏目前纯只读是功能级缺口）；**"自上次查看"差异视图**（月频用户差异比现状重要+我批过的事的后续必须自动回到我面前）。

**AI提效他会信的形态**（有对照/有金额/可审计）：快手组vs未接入组同期对比（编不了）；"提前Y小时发现拦截X次折算避免Z万"每条可点开证据链（随机抽查能追到账户）；人均管户X→Y且达成不降；**采纳率**（1000条采纳30=噪音机，200条采纳150=真有用，生成量指标直接无视）；**报告带"AI判断错的X条及原因"**（全是捷报=PPT）。

**一条组织提醒（博弈文档漏的纵向）**：VP直接看系统=负责人信息中介地位被绕过→**异常先到负责人视图、隔4小时处置窗口再上VP屏**（或同步推负责人"VP今天会看到什么"）；不做这个时差设计，负责人会本能抵制开放这屏，产品在他那关推不动。
