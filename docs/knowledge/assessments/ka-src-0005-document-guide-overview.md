## “每篇介绍”包含什么

每条私有索引记录至少包含：

- `child_asset_id`、父 `document_id`、标题、相对路径和分组；
- 内容格式、字节数、SHA-256；
- 一段“讲什么”的抽取式介绍、章节线索和主题标签；
- `substantive/short/stub/empty` 质量状态；
- NUL、凭证清除、重复、历史/废弃路径、伪 PDF、无效 JSON 等异常；
- `extractive_unreviewed / unreviewed_child / not_ready / confidential` 治理状态；
- 私有 `storage_ref`。

## 使用边界

1. 导读解决“先判断哪个文件值得看”，不证明原文正确、最新或仍可用。
2. 介绍由文件名、正文前部信息句和章节标题抽取，不能替代阅读全文；表格、图片、链接缺失时可能只恢复部分含义。
3. 空文件只说明文件名拟表达的主题，不补造内容。
4. 重复件仍保留独立 `child_asset_id` 和路径，避免破坏来源可追溯性；引用时应优先使用其 duplicate group 的 canonical 成员。
5. 任何子文件要成为正式口径或进入产品知识库，仍需单篇分配 `document_id`、确认责任方/时效/ACL、独立评估和审查。
