## 1. 平台与 MAPI 定位

- 官方名称：快手磁力引擎开放平台。
- Marketing API（MAPI）：把快手商业广告投放与分析能力以 API 开放给广告主、代理商和第三方服务商。
- 我方定位：MAPI 是快手 provider 的官方能力上限证据；`kuaishou-cli` 是其中少量路径的执行壳；奇航仍是一期既定数据主链路。

官方入口：[快手磁力引擎 DSP/MAPI 文档](https://developers.e.kuaishou.com/docs?docType=DSP&documentId=&menuId=3033)。

## 2. 核心对象层级

```text
广告主账户 advertiser
└─ 广告计划 campaign
   └─ 广告组 unit / ad group
      └─ 广告创意 creative
         └─ 图片/视频/文案/落地页等素材与承接资产
```

| 对象 | 职责 | KA 产品映射 |
|---|---|---|
| 广告主账户 | 授权、资质、资金、账户级状态 | 账户资源、权限健康、数据健康 |
| 广告计划 | 投放目标和上层策略容器 | 基建管理、账户结构树、复制方案 |
| 广告组 | 预算、出价、定向、时段、版位等主要执行粒度 | 调价/调预算/时段、变更集、工作流原子节点 |
| 广告创意 | 展示素材和审核状态 | 商品素材、创意审核、素材效果分析 |

官方代表页：创建计划 `documentId=2565`、创建广告组 `2570`、创建创意 `2577`。引用时附页面版本、更新时间和 endpoint，不只写 documentId。

## 3. 状态与写操作语义

- 查询/list/get 与创建/create、更新/update、状态修改不是同一风险级。
- 计划/组/创意状态修改页的删除语义可能连带影响下级对象。
- “关停”、“暂停”、“删除”不得在我方合并为一个模糊 action；provider action 必须保留媒体原始语义和连带影响。
- 所有写操作继续走：生成变更集 → dry-run/预览 → 确认 → 幂等执行 → 媒体态回查 → T+1 效果回收。

## 4. 预算、出价、定向与版位

- 预算/出价的单位、上下限、可改时机必须以目标接口字段为准，不跨字段猜单位。
- 定向、版位、优化目标和出价方式存在组合约束，不能只验证单字段枚举。
- 官方有曝光/转化预估与投放预估曲线工具（`documentId=2736/2737`），可作为 What-if 输入证据，不代表我方估计或效果承诺。

## 5. 转化目标与归因

- 公开目录有转化目标列表/管理相关页（代表 documentId `2667/2668/2671`）。
- 媒体帐面转化、后端 BI 真实转化和 KA 考核口径是不同语义层；MAPI 字段不能覆盖我方 canonical metrics。
- 策略中心必须保留数据截止时间、归因口径、来源系统和 Gap 计算依据。

## 6. 报表粒度

官方实时报表代表页：

| 粒度 | documentId | KA 用途 |
|---|---:|---|
| 广告主 | 2606 | 账户监控、奇航/MAPI 口径对照 |
| 计划 | 2607 | 计划层树、异常定位 |
| 广告组 | 2608 | 出价/预算/定向效果回收 |
| 创意 | 2609 | 素材表现、审核与跑量分析 |

目标接口页的日期范围、对象 ID 批量上限、分页上限可不同；provider preflight 需按 endpoint/version 存储，不用一个“通用快手限制”覆盖。

## 7. 素材与审核

- 图片/视频有上传和列表能力；视频列表可包含转码、审核、质量、重复度、跑量分、内容标签、来源等字段。
- 创意审核详情可返回商业/社区审核状态、拒绝原因、限流原因和修改建议。
- 这些字段可进入素材策略和审核看板，但官方已标废字段不进 canonical 主模型。

## 8. 授权、Scope 与 Token

- Scope 代表页 `documentId=2540`；Token 代表页 `2541/3085`；授权账户列表 `3025`。
- 结构化状态：

```text
documented → authorized → white-listed(if required) → wrapped → method aligned → runtime verified → product enabled
```

- 开发文档可读只证明 `documented`；不得回答“当前账户能用”。

## 9. 频控、创建上限与官方冲突

- 频控/创建限制代表页 `2544/2545`。
- 已知官方页内冲突：v2 与 `gw/dsp` 路径、计划数 1000/500、广告主信息 POST/GET。
- 冲突处置：标 `official_conflict`，以当前目标页 + 授权账户探针 + 媒体确认裁定，不静默择一。

## 10. 媒体原生自动化

创建计划页出现 `auto_build`、`auto_adjust`、`auto_manage`。正确解读：

- 它们是媒体原生开关/字段，不是 KA 工作流、变更集或 AI 策略引擎的已实现证据。
- `auto_build` 公开页标白名单；字段存在不等于全账户可用。
- 严格实验期间，媒体原生自动优化可能改变唯一变量或流量分配；未补证前默认冻结。

## 11. 对当前产品的取舍

### 一期候选（须业务 owner 和运行实证）

- 授权账户/权限健康。
- campaign/unit/creative 只读结构同步。
- 审核与媒体态回查。
- 奇航缺失粒度/字段的小范围补充。
- 已批准写操作所需的少量执行端点，仍走确认门。

### 后续路线图

- 素材质量/重复度/审核策略。
- 异步长周期报表与多源对账。
- 媒体原生自动基建/智投的 Shadow Mode 和实验污染评估。
- SPI/事件订阅是否可减少轮询。

### 不建议做

- 一次性封装 352 个当前路径或将 59 条机器初筛整体当一期范围。
- 代理商充值/转账/退款/共享钱包写操作。
- CRM 外呼、企微成员、第三方支付等超出当前 KA 产品的能力。
- 让 Agent 绕过确认门直接调价、关停、删除或改时段。
