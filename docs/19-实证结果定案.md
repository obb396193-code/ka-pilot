## 2026-08-20：启航 `get_data` 双口径只读探针

### 已确认

| 口径 | 实证结论 | 产品用途 |
|---|---|---|
| 当天实时 | `account_realtime` / `ad_realtime` 命中当天数据，且 `last_sync_time` 显示分钟级同步新鲜度 | 实时监控、日内诊断、异常判断；页面展示“更新于”时间，不用于结算 |
| 离线结算 | 本次探针中 D-1 尚未产出、D-2 命中 | 晨报、结算、对账；运行时动态探测最新已产出分区，不硬编码 T-1 或 T-2 |

- 两条口径不是互相替代：当天运营看实时，结算对账看离线；产品界面必须显式展示口径、数据日与更新时间。
- `get_data` 为内网 HTTP GET，显式传入合法 userId；四个 resource 均返回结构化 JSON，日期使用 `YYYYMMDD`。
- 当前一期主取数路径按老板拍板走**启航 `get_data`**。BI 后台拉取保留为备用/增强路径；当前尚未完成产品侧接入和等价性验证，不作为一期阻断。
- 详细脱敏证据与代码适配见 `docs/evidence/integration/2026-08-20-qihang-readonly-os-probe.md` 和 `docs/evidence/B10-真实启航只读适配报告.md`。

### 第二轮只读探针补证（2026-08-20）

- `hh` 已由文档/源码意图升级为真实执行：相邻 hh 与不传 hh 的共同广告逐行指标单调非降，确认是“截至该小时（0..hh 含）累计”。小时窗口可用 `cum(hh)-cum(hh-1)` 计算。
- 较早 hh 尚无数据的广告整行不返回；返回行本轮无 null、缺省数字补 0。差分必须取 ID 并集，缺上一行可按 0，缺当前行不能按 0。
- offline 跨日区间含首尾并带 `ds`；成熟数据日的跨日/单日结果逐行哈希一致。
- D-1 在两次午后探针之间从空变为有行，进一步确认“最新已产出分区”随时间变化；产品必须重查和修订。
- 源码与文档不存在分区 ready/complete/latest marker。空数组与非空都不能单次证明分区完整，多次稳定也只能标产品侧 provisional/stable。
- 无 accountIds 的全范围 `ad_realtime` 恰好命中固定整数边界，第二轮当时仅能标疑似截断；该判断已由下方第三轮账户分片对照升级为已证实静默截断。
- 完整脱敏证据：`docs/evidence/integration/2026-08-20-qihang-readonly-os-probe-round2.md`。

### IdeaLab ASR 真实格式诊断补证（2026-08-21）
