## 6. 通用规则

1. **每页 = sidebar-shell 布局 + SiteHeader + 内容区**，内容区只拿模板的 Card/DataTable/Chart/Drawer/Tabs 拼；缺的按 `agent-workflow.md` 查 `capabilities.json` → 从 `source-cache` 复制官方源码。
2. 状态八态每页都要：normal/loading/empty/partial/stale/error/forbidden/disabled；空态「示例」角标+解锁条件，**绝不假数据**。
3. 前端永不算数；缺数显 `−`。
4. 字体：等老板在 `font-comparison.html` 拍板前用模板默认（Geist+系统中文），**不动**。
5. Storybook/ECharts 主题桥/Playwright 视觉回归**尚未接入** `apps/web`，不要在交付里写"已有"。
6. 顺序（老板 9-5 深夜再改）：**登录 → 数据分析 → 账户池 → 工作台 → 投放任务**；账户池/工作台/任务等 v1.5.1；每页做完老板看一眼再下一页。
