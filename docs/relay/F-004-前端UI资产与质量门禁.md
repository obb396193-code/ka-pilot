## 老板拍板的新来源

- **Vercel AI Elements：正式准入。** 用于全局 Agent 悬浮入口、对话抽屉、消息、流式输出、推理、工具调用、来源引用和 Prompt 输入。不要自己另造一整套聊天 UI。
- **Kibo UI：正式准入。** Gantt、Kanban、Editor、Dropzone、Color Picker、复杂 Calendar 优先查它。官网颜色可以改，但只能映射到项目语义 token，不散落硬编码颜色。
- **Dice UI：正式准入。** Data Grid、File Upload、Kanban、Time Picker 等复杂交互进入正式候选；与 ReUI/coss/TanStack 重叠时必须同业务容器并排比较。
- **Animate UI、Motion Primitives：选择性准入。** 只在具体微交互出现时与 Aceternity/Magic UI/React Bits 对比，少量接入，支持 reduced motion；Animate UI 许可证限制单列。

以上“准入”不等于源码已下载或依赖已安装。当前五库仍是 `discovery-only/not-cached/not-installed`；任何运行时接入先完成官方组件级核验、依赖/许可证/来源记录。

## 本批次需要建立的四层能力

1. **Storybook 组件展台**：先覆盖 KPI 卡、数据健康横幅、筛选条、Data Grid、状态 chip、空/错态、详情抽屉、确认弹窗、Agent 悬浮入口与对话抽屉；每项覆盖正常/加载/空/错/过期/无权限/禁用。
2. **ECharts 6 正式图表层**：趋势、分组、堆叠、散点、漏斗和下钻使用 ECharts；现有 Recharts 仅保留模板占位或经明确保留的轻量图。业务口径仍由 domain/API 提供。
3. **tweakcn + Design Tokens 主题桥**：颜色、文字、边框、圆角、阴影、状态色和图表 palette 均使用语义 token；生成 CSS variables 与 ECharts theme，禁止组件锁死某一 preset。
4. **Playwright + 键盘/无障碍门禁**：核心页面覆盖 1440/1366/390 截图、关键交互、console、Tab/Escape/方向键/焦点回收和 reduced motion。

## 实施顺序

1. F-001R 修复完成并提交，先取得干净基线；不要把本条混入当前结构修复 commit。
2. 输出本批次页面的能力清单与候选来源；同能力多候选按 UI 资产模板对比，老板拍板后才写 `preferred`。
3. 建 Storybook 与语义 token/ECharts theme 基座，再实现业务组件 stories。
4. 页面只组合已验证组件并接契约 mock/API，不在页面内复制组件或计算业务指标。
5. 加 Playwright 视觉/键盘回归，按 `frontend-product-standard.md` Definition of Done 自检。
6. 交付 SHA、Storybook 入口、页面入口、截图差异结果、来源清单和未解决风险。

## 边界

- 不改九项导航、路由树、API 数据形状和指标口径；契约缺口回抛 arch。
- 不一次性安装五个候选库；只复制当页选中的官方源码，并按来源隔离。
- 不从搬运站、镜像或会员绕过渠道取得源码。
- 不把“官网看过”“目录收录”“源码缓存”“运行时安装”“业务适配”混为同一状态。

## 验收

- lint、build、核心 stories、Playwright 视觉/交互、键盘/焦点与主题切换全部通过。
- 数据页满足“结论与健康 → KPI → 筛选 → 趋势证据 → 明细下钻 → 下一步动作”。
- KPI/图表/表格均能追溯单位、比较基线、数据更新时间、时区和筛选上下文。
- 第三方源码有官方 URL、许可证、精确 ref/hash、本地路径和修改说明。
