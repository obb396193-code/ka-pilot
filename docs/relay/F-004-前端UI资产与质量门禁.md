## 可直接查看的真实预览

- 入口：`docs/frontend/ui-assets/showroom.html#discovery`
- 预览不是截图：17 条产品线统一进入比较墙，16 个离线 sandbox frame 真实运行 27 个官方代表资产；React Bits Pro 是唯一锁定卡，缓存、bundle、frame 均为 0。
- 分组：基础组件 3、数据业务 5、动效视觉 6 个实时 + 1 个锁定、Agent 1、主题系统 1。先看风格/能力差异，再回到 7,056 条目录查遗漏。
- 真实 Chrome `file://` 已在 1440×900、390×844 验收：16/16 frame 非空、主文档/全部 frame 溢出 0、console error 0、HTTP(S) 请求 0；详见 `docs/frontend/ui-assets/reviews/2026-08-20-17-library-showroom-qa.md`。
- 预览 bundle 只用于选型，禁止把 `live-previews/assets/*.js` 反编译或直接复制进产品。产品源码必须从 `source-cache/manifest.json` 指向的官方 payload/raw source 复制，再按来源隔离适配。
- 同一能力命中多个来源时，先用展厅和官方页筛一轮，再在相同业务容器做并排样板交老板拍板；不得由 Agent 私自把目录候选写成 `preferred`。
- 比较墙只证明代表源码可运行，不代表产品已选型或安装；正式使用必须从 `source-cache/manifest.json` 指向的官方 payload/raw source 复制，不能从预编译 bundle 反推源码。

## 本批次需要建立的四层能力

1. **Storybook 组件展台**：先覆盖 KPI 卡、数据健康横幅、筛选条、Data Grid、状态 chip、空/错态、详情抽屉、确认弹窗、Agent 悬浮入口与对话抽屉；每项覆盖正常/加载/空/错/过期/无权限/禁用。
2. **ECharts 6 正式图表层**：趋势、分组、堆叠、散点、漏斗和下钻使用 ECharts；现有 Recharts 仅保留模板占位或经明确保留的轻量图。业务口径仍由 domain/API 提供。
3. **tweakcn + Design Tokens 主题桥**：颜色、文字、边框、圆角、阴影、状态色和图表 palette 均使用语义 token；生成 CSS variables 与 ECharts theme，禁止组件锁死某一 preset。
4. **Playwright + 键盘/无障碍门禁**：核心页面覆盖 1440/1366/390 截图、关键交互、console、Tab/Escape/方向键/焦点回收和 reduced motion。

## 边界

- 不改九项导航、路由树、API 数据形状和指标口径；契约缺口回抛 arch。
- 不一次性安装五个候选库；只复制当页选中的官方源码，并按来源隔离。
- 不从搬运站、镜像或会员绕过渠道取得源码。
- 不把“官网看过”“目录收录”“源码缓存”“运行时安装”“业务适配”混为同一状态。

## 验收

- lint、build、核心 stories、Playwright 视觉/交互、键盘/焦点与主题切换全部通过。
- 数据页满足“结论与健康 → KPI → 筛选 → 趋势证据 → 明细下钻 → 下一步动作”。
- KPI/图表/表格均能追溯单位、比较基线、数据更新时间、时区和筛选上下文。
- 第三方源码有官方 URL、许可证、精确 ref/hash、本地路径和修改说明。
