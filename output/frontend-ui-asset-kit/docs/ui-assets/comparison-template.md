## 逐项说明

每个候选必须写：

1. 官方组件名、preview、source/registry、guide；
2. 默认交互和视觉与需求的命中点；
3. 中文、密度、暗色、移动端、空/错/加载的适配情况；
4. focus、键盘、portal、虚拟化或动画性能注意点；
5. 许可证、付费资产、复制修改和再分发边界；
6. 预计新增依赖和需要改动的本地文件；
7. 推荐/不推荐的明确理由。
