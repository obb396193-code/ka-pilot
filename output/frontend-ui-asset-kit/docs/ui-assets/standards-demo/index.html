不是告诉前端“永远必须这样”，而是把字体、数字、留白、密度和动画放进真实数据场景里。你可以现场切换，再判断哪个组合更清晰、更好看。

这里验证什么？

扫一眼能否找到结论；金额和 CPA 是否对齐；移动端是否仍有层级；动画是否帮助理解，而不是抢走注意力。
